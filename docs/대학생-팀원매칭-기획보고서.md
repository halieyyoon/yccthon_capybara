# 대학생 프로젝트 팀원 매칭 서비스 — 사전 기획 보고서

> **문서 목적**  
> 서비스 개발을 시작하기 전에 MVP의 핵심 3가지 기능, 디자인 방향, 사전 검증 및 준비 과제를 알기 쉽게 정리한 기획서입니다.

---

## 1. 서비스 개요

### 한 줄 정의
스펙 대신 **약점·성향·가능 시간표**를 입력하면, 내 AI 분신이 먼저 가상 팀플을 돌려보고 가장 합이 좋은 4인 팀과 정기 회의 시간까지 추천해 주는 **무거절 대학생 팀 빌딩 서비스**

### 해결하려는 문제
- **작성 부담**: 저학년·초보자는 링크드인이나 포트폴리오에 쓸 경력이 부족해 시작부터 포기한다.
- **기대치 불일치**: 기존 게시판(에브리타임·링커리어)은 “열심히 하겠다”는 말뿐이라 참여 온도(진지 vs 편함), AI 활용 태도, 협업 지뢰를 미리 알기 어렵다.
- **거절 스트레스**: 좁은 캠퍼스에서 직접 쪽지로 거절하거나 읽씹당하는 심리적 부담이 크다.

### 초기 런칭 전략
- **1차 대상**: 연세대학교 재학생 (`@yonsei.ac.kr` 인증) — 초기 50~200명 확보
- **확장 전략**: 타 대학 확장 → 여러 전공이 섞이는 팀 빌딩 → 공모전 주최사 맞춤형 추천 광고로 수익화

## 2. MVP 핵심 기능 3가지

초기 참여자가 적을 때도 첫날부터 차별화를 체감할 수 있도록 **딱 3가지 핵심 기능**에만 집중합니다.

### 기능 1. 2분 컷 ‘약점·성향·가능 시간표’ 프로필 작성 *(매칭 #4 · 기술 #1, #2)*
경력이 적어도 부담 없이 끝낼 수 있는 카드형 프로필 입력 흐름입니다.
- **학교 인증**: `@yonsei.ac.kr` 이메일 인증
- **경력 자동 채우기 (선택)**: 링크드인 PDF·이력서·GitHub 주소를 올리면 AI가 초안 자동 입력
- **필수 입력 4요소**
  - **참여 온도 & 가능 시간표**: 수상/진지 ↔ 경험/편함, 주당 투입 시간 + **When2Meet처럼 드래그해서 고르는 주간 가능 시간표**
  - **AI 활용 스타일**: 짧은 실제 상황 질문 3개로 자동 분류 *(예: AI 가속형 / 검증 중심형 / 직접 구현형)*
  - **약점 2장 + 강점 2장**: 보기 선택 + 짧은 자유 입력 *(예: 약점 `발표 울렁증`, 강점 `밤샘 백엔드 구현`)*
  - **협업할 때 절대 못 참는 행동 1~2개**: *(예: `연락 두절`, `이해 없이 AI 복붙`)*

### 기능 2. AI 분신 사전 모의회의 & 팀 조합 리포트 *(매칭 #1 · 기술 #2, #3)*
게시판 목록과 좌우 스와이프를 대체하는 서비스의 심장입니다.
- **공모전/주제 선택 → AI 분신 보내기**: 관심 공모전을 고르면 가상 첫 회의 실행
- **2단계 비용 통제 구조**
  - 1단계(0원): DB에서 `온도 일치 + 가능 시간표 겹침 + 약점↔강점 보완 − 협업 지뢰 충돌` 점수로 상위 2~3팀만 추림
  - 2단계(저비용): 선정된 2~3팀만 **정해진 형식으로 AI를 1번 호출**해 6턴 가상 회의와 요약 생성
- **결과 카드 구성**
  - **팀 퍼즐 보완 요약**: 누가 누구의 약점을 덮어주는지 정리
  - **정기 회의 추천 시간 TOP 3**: 4명이 매주 정기적으로 만나기 좋은 겹치는 시간대 자동 추천 *(When2Meet형)*
  - **모의회의 하이라이트**: 실제 첫 회의 분위기 4~5줄 미리보기
  - **첫 회의 합의 포인트**: 초반에 맞출 1가지 제안 *(예: AI 초안 활용 범위)*

### 기능 3. 무거절 상호 소집 & 매주 금요일 일괄 매칭 *(매칭 #5)*
거절 피로를 없애고 초기 참여자들이 한 시점에 모이게 만드는 결성 방식입니다.
- **누가 먼저 눌렀는지 비공개**: 마음에 드는 조합에 “만나볼래요”를 눌러도 상대에겐 *“AI 분신이 딱 맞는 팀을 찾아왔어요”*로만 알림
- **서로 수락 시 실명 공개**: 팀원들이 수락할 때만 실제 이름·학과·상세 프로필 공개
- **매주 금요일 일괄 매칭**: 상시 소집과 함께 매주 금요일 밤 10시에 그 주 신청자들을 한꺼번에 매칭해 동시 알림 → 빠른 수락 유도
- **정기 회의 시간표 & 외부 채팅 연결**: 팀 확정 시 4인 시간표 겹침 표(When2Meet형)를 바로 보여주고 카카오톡 오픈채팅·디스코드로 연결

### 이번 첫 버전(MVP)에서 과감히 빼는 것
- 자체 실시간 채팅·메신저
- 실시간 20분 협업 화이트보드 *(동시 접속자 확보 후 v3)*
- 2D 온도·시간표 지도 화면 *(에브리타임 시간표 연동과 함께 v2)*
- 링크드인 양방향 자동 동기화 *(정책 제약 → PDF 자동 입력 + 완료 후 복붙 요약으로 대체)*

## 3. 디자인 방향 & 말투

### 전체 디자인 느낌
> **“가볍지 않은 솔직함, 무겁지 않은 전문성”**

- 링크드인처럼 딱딱한 취업·이력서 느낌은 피하고, 소개팅 앱처럼 가벼운 느낌도 피합니다.
- **잡지처럼 여백이 넓고 깔끔한 카드 화면**을 지향합니다. *(참고: Linear의 깔끔함 + Toss의 한 화면 한 질문 흐름 + 카드 게임의 직관성)*

### 화면 디자인 기준 초안
- **화면 크기**: 모바일 웹 최우선 *(에브리타임·카톡 단톡방 링크를 눌러 설치 없이 바로 사용)*
- **배경 & 글자**: 순백(`#FFFFFF`)보다 눈이 편한 **따뜻한 미색(`#FAF9F6`)** 배경 + 짙은 먹색(`#18181B`) 글자
- **핵심 버튼 색상**: 신뢰감 있는 파란색(`#2563EB`) 1가지를 시작하기·만나볼래요 버튼에만 집중 사용
- **배지 색상**: 참여 온도, 약점·강점 카드는 눈이 덜 피로한 연한 파스텔 배지로 구분
- **글꼴**: `Pretendard` 기반, 넉넉한 줄 간격과 여백 유지

### 핵심 화면 포인트
1. **프로필 작성**: 긴 설문지 금지. **한 화면에 질문 하나 + 버튼 터치 + 주간 가능 시간표 드래그**로 2분 안에 완료.
2. **AI 분신 회의 대기**: 지루한 로딩 아이콘 대신 *“내 분신이 경영학도·디자이너와 첫 회의를 맞춰보는 중…”*처럼 진행 상황을 짧게 중계.
3. **결과 카드**: 한 화면에 팀 1개씩 집중 노출. `퍼즐 요약 → 추천 정기 회의 시간 → 말풍선 4~5줄 요약 → 합의 포인트 1줄 → [만나볼래요]` 흐름.
4. **안내 문구 톤**: 면접 보거나 평가하는 어투를 빼고, 솔직하고 유쾌한 대학생 대화체 유지.

## 4. 개발 착수 전 해야 할 일 (체크리스트)

코드를 짜기 전에 아래 **4가지 영역**을 먼저 정리하면 시행착오를 크게 줄일 수 있습니다.

### A. 사전 검증 — 개발 전에 진짜 쓸 만한지 확인
- [ ] **연세대 재학생 10~15명 인터뷰**: 실제 공모전 팀플 실패 경험, 자주 겪은 협업 지뢰, 프로필 작성 시 부담 요소 수집
- [ ] **구글 폼 사전 테스트**: 구글 폼으로 20명의 약점·성향·시간표를 모은 뒤, AI로 직접 모의회의 리포트를 만들어 전달 → *“이 리포트를 보고 실제로 만나고 싶은가?”* 반응 확인
- [ ] **초기 집중 분야 확정**: IT·개발 해커톤 중심 vs 경영·기획·마케팅 통합 공모전 중 1차 범위 결정
- [ ] **서비스 이름·도메인 확정**: 듣자마자 감이 오고 입에 붙는 이름 선정

### B. 데이터·AI 사전 설계
- [ ] **프로필 선택지 목록 확정**
  - 약점 카드 12~15종 / 강점 카드 12~15종
  - AI 활용 스타일 3~4유형 + 상황 질문 3문항
  - 협업 지뢰 표준 항목 8~10종
- [ ] **1단계 매칭 점수 공식 초안 작성**: 온도·시간표 겹침·약점 보완·지뢰 감점 비중 정하기
- [ ] **가상 모의회의 AI 프롬프트 다듬기**: 말투가 뻔하거나 오글거리지 않도록 실제 예시로 20회 이상 테스트하고 출력 형식 고정
- [ ] **초기 예시 공모전 확보**: 연세대생이 관심 가질 실제 공모전·해커톤 10~20건 정리

### C. 화면 설계
- [ ] **전체 화면 목록 7~9개 이내로 고정**: 첫 화면 → 인증 → 프로필 작성 → 공모전 선택 → 분신 대기 → 결과 카드 → 팀 확정 → 내 프로필
- [ ] **Figma 핵심 화면 시안 제작**: 프로필 작성, 모의회의 결과 카드, 팀 확정(시간표 겹침 포함) 화면 3종 먼저 완성해 지인 피드백 반영
- [ ] **안내 문구 & 공유 이미지 준비**: 거절감을 주지 않는 알림 문구와 카카오톡 링크 공유 시 뜰 미리보기 이미지 준비

### D. 운영·법무·초기 홍보 준비
- [ ] **필수 안내 문구 준비**: 개인정보 처리방침, 이용약관, AI 모의회의는 시뮬레이션이라는 고지, 실명 공개 동의
- [ ] **안전장치 정책**: 허위 프로필·비매너 신고 절차, 부정 평판 비공개 원칙 정리
- [ ] **초기 참여자 50~100명 확보 계획**: 연세대 학회·동아리·에브리타임 홍보 채널 정리 및 첫 ‘금요일 밤 일괄 매칭’ 일정 잡기
- [ ] **성공 기준(KPI) 정하기**
  - 2분 프로필 작성 완료율 *(목표 70% 이상)*
  - 결과 카드 확인 → “만나볼래요” 클릭률 *(목표 35% 이상)*
  - 실제 팀 확정 비율 및 2주 내 재방문 비율

## 5. 개발 전 준비 일정 (권장 2~3주)

### 1주차 — 가설 확인 & 범위 확정
- 초기 집중 분야 확정 + 연세대 재학생 10~15명 인터뷰
- 20명 대상 구글 폼 사전 테스트로 AI 모의회의 리포트 반응 확인

### 2주차 — 선택지·프롬프트·화면 시안 완성
- 약점·강점·AI 질문·지뢰 선택지 목록 및 매칭 점수 공식 확정
- 가상 모의회의 AI 프롬프트 튜닝 및 비용·응답 속도 점검
- Figma 핵심 화면 시안 제작 및 모바일 사용성 점검

### 3주차 — 개발 착수 준비 완료
- 기술 스택 및 DB 테이블 구조 확정 *(Next.js + Supabase + Gemini Flash)*
- 예시 공모전 15건 등록 준비, 약관 문구 정리, 초기 홍보 채널 확보
- **MVP 개발 시작**
