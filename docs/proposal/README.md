## 한눈에 보는 제안 요약

- **추천 이름**: `모의팀플` *(1순위)* / `팀프리뷰` *(2순위)* / `팀온도` *(3순위)*
- **한 줄 컨셉**: 스펙 대신 약점·성향·AI 활용 방식을 넣으면, 내 AI 분신이 먼저 가상 팀플을 돌려보고 가장 합이 좋은 4인 팀을 데려다주는 무거절 팀 빌딩
- **초기 타깃**: 연세대학교 재학생(`@yonsei.ac.kr`) → 타 대학 크로스전공 확장
- **권장 스택**: Next.js (App Router) + Supabase (Postgres · Auth · RLS) + Gemini Flash (Structured JSON) + Vercel
