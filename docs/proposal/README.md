## 확정된 MVP 핵심 3가지 기능 요약

1. **3단계 매칭 엔진**: `1단계 다차원 클러스터 분석` → `2단계 AI 아바타 모의회의` → `3단계 20분 파일럿 해커톤`
2. **퍼즐 프로필 (+ 매주 일괄 매칭 / Weekly Drop)**: 참여 목적(재미 vs 수상·취업)에 따라 디자인이 달라지는 장점·약점 퍼즐 프로필 + 주간 일괄 매칭 & 정기 회의 시간 자동 추천
3. **CV 템플릿 제공**: 초보자도 쉽게 채우는 공모전·해커톤용 CV 템플릿 + 이력서/링크드인 PDF 자동 채우기 & 완료 후 내보내기
