# 04. MVP 핵심 3가지 기능

> **원칙**  
> 첫 버전(MVP)은 **“2분 프로필 작성 → AI 모의회의 리포트 확인 → 무거절 팀 확정 & 정기 회의 시간 추천”**이라는 단 하나의 핵심 흐름을 매끄럽게 완성하는 데 집중한다.

---

## 기능 1. 2분 컷 ‘약점·성향·가능 시간표’ 프로필 작성

경력이 부족한 저학년도 2분 만에 부담 없이 끝낼 수 있는 카드형 프로필 입력 흐름이다.

### 구성 요소
1. **학교 이메일 인증**: `@yonsei.ac.kr` 인증으로 같은 학교 학생만 모이는 신뢰 공간 확보
2. **경력 자동 채우기 (선택)**: LinkedIn PDF, 이력서, GitHub 주소를 올리면 AI가 역할·사용 기술·경력 초안을 자동 입력
3. **필수 입력 4가지**
   - **참여 온도 & 가능 시간표**: `진지하게 수상 (90°)` / `균형 있게 완주 (65°)` / `가볍게 경험 (36.5°)` + 주당 투입 시간 + **When2Meet처럼 드래그해서 고르는 주간 가능 시간표** *(정기 회의 시간 자동 추천에 바로 활용)*
   - **AI 활용 스타일**: 짧은 실제 상황 질문 3개로 자동 분류
     - `AI 적극 가속형` · `AI 초안+검증형` · `직접 구현 지향형`
   - **약점 카드 2장 + 강점 카드 2장**: 보기 선택 + 짧은 자유 입력
     - 예시(약점): `발표 울렁증`, `디자인 감각 부족`, `데이터 분석 서툼`, `일정 관리 약함`
     - 예시(강점): `빠른 프로토타이핑`, `장표·스토리라인 정리`, `AI 프롬프트 활용`, `사용자 인터뷰·리서치`
   - **협업할 때 절대 못 참는 행동(협업 지뢰) 1~2개**
     - 예시: `24시간 이상 연락 두절`, `이해 없이 AI 복붙`, `마감 직전 잠수·수정`, `회의록 미확인`

## 기능 2. AI 분신 사전 모의회의 & 팀 조합 리포트

기존 게시판 목록과 좌우 스와이프를 대체하는 핵심 차별화 기능이다.

### 동작 방식
1. 사용자가 관심 공모전(또는 자유 프로젝트 주제)을 고르고 **“내 AI 분신 보내기”** 클릭
2. **1단계 빠른 후보 추리기 (비용 0원)**: 전체 인원 중 온도 일치·시간표 겹침·약점↔강점 보완·지뢰 회피 점수로 **상위 2~3개 팀 조합(3~4인)**만 먼저 선정
3. **2단계 AI 가상 첫 회의 생성 (조합당 1회 호출)**: 선정된 2~3팀의 성향을 반영해 **6턴짜리 가상 첫 회의**를 한 번에 생성

### 결과 카드에 보이는 내용
- **팀 퍼즐 보완 요약**: 누가 누구의 약점을 어떻게 메우는지 3줄로 정리
- **정기 회의 추천 시간 TOP 3 (When2Meet형)**: 4명의 가능 시간표가 모두 겹치는 시간대를 자동 계산 *(예: 화 19:00~21:00 · 목 14:00~16:00 · 일 20:00~22:00)*
- **모의회의 하이라이트 (4~5줄)**: 실제 첫 회의에서 아이디어와 역할이 어떻게 풀리는지 대화 미리보기
- **첫 회의 합의 포인트 (1줄)**: *“목표 온도·투입 시간 일치 / AI 초안 활용 범위만 초반에 맞추면 최상”*
- **실명 비공개 유지**: 수락 전까지는 닉네임·역할·약점/강점 조합만 표시

## 기능 3. 무거절 상호 소집 & 매주 금요일 일괄 매칭 (+ 정기 회의 시간 확정)

좁은 캠퍼스의 거절 스트레스를 없애고, 초기 참여자가 적을 때도 매칭 성공률을 높이는 결성 방식이다.

### 동작 방식
- **누가 먼저 눌렀는지 비공개**: 마음에 드는 조합에서 **“이 조합으로 만나볼래요”**를 눌러도, 상대방에겐 누가 먼저 눌렀는지 숨기고 *“AI 분신이 딱 맞는 팀을 찾아왔어요”*로 알림 발송
- **서로 수락할 때만 신원 공개**: 팀원들이 수락(과반 또는 전원)할 때만 실제 이름·학과·상세 프로필 공개
- **거절 알림 없음**: 기한 내 성사되지 않아도 거절 통보 없이 조용히 종료해 눈치·감정 소모 제거
- **매주 금요일 일괄 매칭**: 상시 소집과 함께 매주 금요일 밤 10시에 그 주 신청자들을 한꺼번에 매칭해 동시 알림 → 다 같이 앱을 열어 빠른 팀 결성 유도
- **정기 회의 시간표 & 외부 채팅 연결**: 팀이 확정되면 4인의 겹치는 시간표(When2Meet형)와 추천 정기 회의 시간 TOP 3를 바로 보여주고, 카카오톡 오픈채팅·디스코드 링크로 즉시 이동

## 이번 첫 버전(MVP)에서 과감히 빼는 기능

| 제외 항목 | 제외 이유 및 추후 반영 시점 |
|---|---|
| 자체 실시간 메신저 | 팀 확정 후 카톡·디스코드로 이동하면 충분 (개발 시간 절약) |
| 실시간 20분 협업 화이트보드 | 동시 접속자가 충분히 늘어난 뒤 이벤트로 도입 (v3) |
| 2D 은하계·시간표 지도 화면 | 핵심 매칭 반응 검증 후 탐색 화면 확장 시 추가 (v2) |
| 링크드인 양방향 자동 동기화 | 정책상 불가 → PDF 업로드 자동 입력 + 종료 후 복붙 요약으로 대체 |

## 해커톤 1분 시연 시나리오
1. `@yonsei.ac.kr` 로그인 → 약점 2장·강점 2장·온도·가능 시간표·AI 질문 3개 **30초 컷 입력**
2. 등록된 공모전 1개 선택 → **“내 AI 분신 보내기”** 클릭
3. 3초 후 도착한 **AI 모의회의 결과 카드 2개** 확인 (퍼즐 보완 + 추천 정기 회의 시간 + 5줄 모의대화 + 합의 포인트)
4. **“만나볼래요”** 클릭 → 상호 수락 → 실명·학과 공개 + 4인 시간표 겹침 확인 & 오픈채팅 연결
