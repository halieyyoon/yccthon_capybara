## 기능 1. 3단계 매칭 엔진 (`클러스터 분석 → AI 아바타 → 파일럿 해커톤`)

단순 키워드 검색이나 스와이프 대신, **데이터 → AI 미리보기 → 20분 실전 체험**의 3단계로 팀 합을 정밀하게 검증한다.

### 1단계. High-Dimensional Cluster Analysis (다차원 클러스터 분석)
- **목적**: 전체 참여자 풀에서 나와 결이 맞고 서로 약점을 메워주는 최적 후보 조합을 빠르게 추린다.
- **반영 차원(피처)**:
  - 참여 온도(재미/경험 vs 수상/취업) & 주당 투입 시간
  - 주간 가능 시간표 겹침 *(When2Meet형 정기 회의 시간 계산)*
  - 장점·약점 카드의 상호 보완 매트릭스
  - AI 활용 스타일(적극 가속 / 검증 중심 / 직접 구현) 및 협업 지뢰 충돌 여부
- **결과**: 상위 2~3개 팀 조합(3~4인) + 4인 공통 정기 회의 추천 시간 TOP 3 자동 산출

### 2단계. AI 아바타 (사전 모의회의)
- **목적**: 실제 사람을 만나기 전, 각자의 퍼즐 프로필을 학습한 AI 아바타끼리 먼저 가상 첫 회의를 돌려 팀 분위기를 미리 본다.
- **결과 카드 구성**:
  - **퍼즐 보완 요약**: 누가 누구의 약점을 메우는지 시각적 모양으로 표시
  - **AI 아바타 모의회의 하이라이트 (4~5줄)**: 첫 회의 대화 흐름 미리보기
  - **추천 정기 회의 시간 TOP 3** & **첫 회의 합의 포인트 1줄**
- **적용 방식**: 프로젝트 성격과 규모에 따라 기본 제공하거나 선택 옵션으로 노출

### 3단계. 파일럿 해커톤 (20분 미니 안건 해결)
- **목적**: 이력서 100줄보다 확실한 실전 호흡 검증. 규모가 크거나 장기 프로젝트에 지원할 때 본선 팀 확정 전 **20분짜리 초미니 협업**을 해본다.
- **동작 방식**:
  - 후보 4명이 해커톤/공모전 안건 중 1개를 선택해 **제한 시간 20분** 안에 짧은 해결안(아이디어 구조·역할 분담)을 함께 정리
  - 종료 후 각자 비공개로 **“이 팀으로 본선 갈래요”** 선택 → 서로 선택한 멤버끼리 최종 팀 확정 & 실명·연락처 공개
- **규모별 옵션**: 가벼운 단기 활동에서는 생략 가능, 큰 해커톤·공모전 지원 시 **“파일럿 해커톤 먼저 해보기”** 버튼 표시

## 기능 2. 퍼즐 프로필 (+ 매주 일괄 매칭 / Weekly Drop)

스펙 나열 대신 **내 성향·장점·약점·현재 상태가 시각적인 퍼즐로 표현되는 프로필**과 **부담 없는 주간 매칭**을 결합한다.

### 상태에 따라 달라지는 퍼즐 프로필
- **장점·약점 퍼즐 카드**: 프로필 옆에 내 장점·약점을 서로 맞물리는 퍼즐 모양으로 표현 *(MBTI 매칭 매트릭스처럼 어울리는 모양끼리 직관적으로 매칭)*
- **유동적인 프로필 상태**: 사용자는 매번 목표가 달라지므로 언제든 상태를 전환할 수 있고, 상태에 따라 퍼즐 디자인과 분위기가 바뀐다.
  - 예: `재미·경험 추구` → 가볍고 경쾌한 퍼즐 분위기
  - 예: `수상·취업 목표` → 단단하고 선명한 퍼즐 분위기
- **가능 시간표(When2Meet형) 포함**: 드래그 한 번으로 주간 가능 시간을 등록해 매칭과 정기 회의 추천에 동시 활용

### + 매주 일괄 매칭 (Weekly Drop) & 무거절 소집
- **매주 일괄 매칭**: 주중에 프로필을 켜둔 참여자들을 매주 정해진 시각(예: 금요일 밤 10시)에 한꺼번에 매칭해 동시 알림 발송 → 초기 참여자가 적을 때도 응답 속도와 성사율 확보
- **무거절 구조**: 누가 먼저 눌렀는지 비공개로 소집하고, 미성사 시에도 거절 알림 없이 조용히 종료

## 기능 3. CV 템플릿 제공

경력 작성 경험이 없는 대학생도 바로 쓰고, 공모전·링크드인까지 연결되는 **대학생 맞춤형 CV 템플릿**을 제공한다.

### 구성 요소
- **가이드형 CV 템플릿**: 작성 경험이 없는 저학년도 생각하며 채울 수 있도록 **선택 항목 + 짧은 서술 가이드**로 구성 *(경력, 공모전·해커톤 이력, 사용 언어·툴, AI 활용 방식, 개인 협업 특성)*
- **기존 파일 자동 채우기 (선택)**: 링크드인 `PDF로 저장` 파일, 기존 이력서, GitHub 주소를 올리면 AI가 CV 템플릿 초안을 자동으로 채워 중복 입력 부담 제거
- **원클릭 내보내기**: 완성된 CV를 공모전 지원서용 PDF/링크로 공유하거나, 프로젝트 완료 후 **링크드인 경력·프로젝트 칸에 바로 붙여넣을 요약본**으로 자동 변환

## 해커톤 1분 시연 시나리오
1. **CV 템플릿 & 퍼즐 프로필 작성**: `@yonsei.ac.kr` 로그인 → CV 템플릿(또는 PDF 자동 채우기) + 장점·약점 퍼즐 카드 + 상태 전환(`재미` ↔ `수상`) 시연
2. **1단계 클러스터 분석 → 2단계 AI 아바타**: 공모전 선택 → 다차원 클러스터로 추려진 팀의 **퍼즐 결합 + 추천 정기 회의 시간 + AI 아바타 모의회의 하이라이트** 확인
3. **3단계 20분 파일럿 해커톤**: 큰 해커톤 옵션 클릭 → 안건 1개 선택 & 20분 미니 해결방 체험 → 상호 수락으로 최종 팀 확정
