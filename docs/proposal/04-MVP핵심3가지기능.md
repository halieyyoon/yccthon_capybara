# 04. MVP 핵심 3가지 기능

> **원칙**  
> MVP는 **“온보딩 → AI 모의회의 리포트 → 무거절 팀 오픈”** 단 하나의 코어 루프를 완벽하게 증명하는 데 집중한다.

---

## 기능 1. 2분 컷 ‘약점·성향’ 온보딩

경력이 부족한 저학년도 2분 만에 부담 없이 프로필을 완성할 수 있는 카드형 온보딩이다.

### 구성 요소
1. **학교 이메일 인증**: `@yonsei.ac.kr` 도메인 인증으로 캠퍼스 신뢰 풀 확보
2. **경력 자동 채우기 (선택)**: LinkedIn PDF, 이력서, GitHub URL 업로드 시 LLM이 역할·스택·경력 초안을 자동 추출
3. **필수 입력 4가지**
   - **참여 온도 & 가능 시간표**: `진지하게 수상 (90°)` / `균형 있게 완주 (65°)` / `가볍게 경험 (36.5°)` + 주당 투입 시간 + **When2Meet형 주간 가능 시간 드래그 입력** *(정기 회의 추천에 바로 활용)*
   - **AI 활용 스타일**: 짧은 상황 질문 3개로 자동 분류
     - `AI 적극 가속형` · `AI 초안+검증형` · `직접 구현 지향형`
   - **약점 카드 2장 + 강점 카드 2장**: 표준 칩 선택 + 짧은 자유 입력
     - 예시(약점): `발표 울렁증`, `디자인 감각 부족`, `데이터 분석 서툼`, `일정 관리 약함`
     - 예시(강점): `빠른 프로토타이핑`, `장표·스토리라인 정리`, `AI 프롬프트 활용`, `사용자 인터뷰·리서치`
   - **협업 지뢰(Deal-breaker) 1~2개**: 절대 피하고 싶은 패턴
     - 예시: `24시간 이상 연락 두절`, `이해 없이 AI 복붙`, `마감 직전 잠수·수정`, `회의록 미확인`

## 기능 2. AI 분신 사전 모의회의 & 팀 조합 리포트

기존의 리스트 탐색과 스와이프를 대체하는 서비스의 핵심 차별화 기능이다.

### 동작 방식
1. 사용자가 관심 공모전(또는 자유 프로젝트 주제)을 선택하고 **“내 AI 분신 보내기”** 클릭
2. **1차 고속 필터링 (비용 0원)**: 전체 풀에서 온도·시간 일치, 약점↔강점 보완, 지뢰 충돌 제거 기준으로 **상위 2~3개 팀 조합(3~4인)** 추출
3. **2차 LLM 가상 킥오프 (조합당 1회 호출)**: 추출된 2~3팀의 멤버 페르소나를 주입해 **6턴짜리 가상 첫 회의**를 생성

### 결과 카드 출력 항목
- **팀 퍼즐 보완 요약**: 누가 누구의 약점을 어떻게 메우는지 3줄 시각화
- **정기 회의 추천 시간 TOP 3 (When2Meet형)**: 4명의 가능 시간표 교집합을 자동 계산해 제시 *(예: 화 19:00~21:00 · 목 14:00~16:00 · 일 20:00~22:00)*
- **모의회의 하이라이트 (4~5줄)**: 실제 첫 미팅에서 아이디어·역할이 어떻게 풀리는지 대화 요약
- **사전 합의 포인트 (1줄)**: *“목표 온도·투입 시간 일치 / AI 초안 활용 범위만 첫 회의에서 합의 권장”*
- **실제 신원은 비공개 유지**: 닉네임·역할·약점/강점 조합만 표시

## 기능 3. 무거절 상호 소집 & 매주 금요일 일괄 매칭 (+ 정기 회의 시간 확정)

좁은 캠퍼스의 거절 스트레스를 없애고, 초기 소규모 풀의 매칭 성공률을 끌어올리는 결성 장치다.

### 동작 방식
- **선요청자 비공개 소집**: 마음에 드는 결과 카드에서 **“이 조합으로 만나볼래요”** 클릭 → 상대방에게는 누가 먼저 눌렀는지 알리지 않고 *“AI 분신이 딱 맞는 팀을 찾아왔어요”* 알림 발송
- **상호 수락 시 신원 언락**: 팀원들이 수락(과반 또는 전원)할 때만 실제 이름·전공·상세 프로필 공개
- **거절 알림 없음**: 미수락 시 조용히 만료 처리해 감정 소모 제거
- **매주 금요일 일괄 매칭 (주간 팀 드롭)**: 상시 소집과 함께 매주 금요일 밤 10시에 일괄 매칭 결과를 동시 공개해 유동성 집중 및 빠른 수락 유도
- **정기 회의 시간 자동 추천 & 외부 채팅 연결**: 팀 확정 시 4인의 겹치는 시간대 히트맵(When2Meet형)과 추천 정기 회의 시간 TOP 3를 바로 보여주며, 카카오톡 오픈채팅·디스코드 링크로 즉시 이동

## MVP에서 과감히 제외하는 기능 (Scope Cut)

| 제외 항목 | 제외 이유 및 반영 시점 |
|---|---|
| 자체 실시간 메신저 | 팀 확정 이후 카톡·디스코드 이동으로 충분 (개발 리소스 절감) |
| 실시간 20분 협업 화이트보드 | 동시접속 유동성이 커진 뒤 라이브 이벤트로 도입 (v3) |
| 2D 은하계·시간표 오버레이 맵 | 핵심 가설 검증 후 탐색 UI 고도화 단계에서 추가 (v2) |
| LinkedIn 양방향 API 동기화 | 정책상 불가 → PDF 업로드 파싱 + 프로젝트 종료 후 복붙 요약으로 대체 |

## 해커톤 1분 데모 시연 시나리오
1. `@yonsei.ac.kr` 로그인 → 약점 2장·강점 2장·온도·AI 질문 3개 **30초 컷 입력**
2. 시드 공모전 1개 선택 → **“내 AI 분신 보내기”** 클릭
3. 3초 후 도착한 **AI 모의회의 결과 카드 2개** 확인 (퍼즐 보완도 + 5줄 모의대화 + 합의 포인트)
4. **“만나볼래요”** 클릭 → 상호 수락 시뮬레이션 → 팀 프로필 언락 & 오픈채팅 연결
