# 06. UI 디자인 제안

> **디자인 핵심 한 줄**  
> **“링크드인보다 가볍고, 틴더보다 똑똑한 — 솔직한 대학생 프로젝트 라운지”**

---

## 1. 브랜드 무드 & 디자인 원칙

- **스타일 키워드**: 에디토리얼 미니멀 · 카드 중심 · 높은 여백 · 위트 있는 대화체
- **참고 감성**: Linear의 정돈된 타이포 + Toss의 한 화면 한 질문 흐름 + 보드게임 퍼즐 카드의 직관성
- **모바일 웹 최우선 (`390px` 기준)**: 에브리타임·카카오톡 단톡방 링크를 눌러 앱 설치 없이 2분 안에 온보딩까지 끝내야 하므로, 모든 인터랙션을 엄지 터치 기준으로 설계한다.

## 2. 디자인 토큰 초안

### 컬러 팔레트
| 용도 | 컬러명 | HEX | 사용처 |
|---|---|---|---|
| **배경** | Warm Off-White | `#FAF9F6` | 전체 페이지 배경 (눈 피로 최소화) |
| **카드 표면** | Pure White | `#FFFFFF` | 카드·모달 배경 + 얇은 보더 `#E7E5E4` |
| **기본 텍스트** | Deep Charcoal | `#18181B` | 제목·본문 |
| **보조 텍스트** | Muted Gray | `#71717A` | 메타 정보·설명 |
| **메인 포인트** | Cobalt Indigo | `#2563EB` | 메인 CTA 버튼, 선택 상태 |
| **약점 카드 틴트** | Soft Coral | `#FFF1F2` / `#E11D48` | 약점 배지 (부담스럽지 않은 파스텔) |
| **강점 카드 틴트** | Soft Mint | `#ECFDF5` / `#059669` | 강점 배지 (보완 관계 시각화) |
| **온도·주의 틴트** | Soft Amber | `#FFFBEB` / `#D97706` | 참여 온도, 사전 합의 포인트 박스 |

### 타이포그래피 & 형태
- **폰트**: `Pretendard` (한글) + `Inter` (숫자·영문)
- **카드 라운드**: `16px` (`rounded-2xl`), 칩/배지 `9999px` (`rounded-full`)
- **그림자 최소화**: 과한 드롭섀도우 대신 `1px solid #E7E5E4` 보더와 여백으로 위계 표현

## 3. 핵심 5개 화면 레이아웃 제안

### 화면 1. 랜딩 & 학교 인증
- 상단: 서비스명 + 한 줄 메시지 (*“스펙 대신 약점을 올리면, AI 분신이 팀플을 먼저 돌려봅니다”*)
- 중단: 실제 모의회의 결과 카드 미니 프리뷰 1장 (스크롤 없이 핵심 차별화 3초 이해)
- 하단 고정 CTA: **`@yonsei.ac.kr`로 2분 만에 시작하기**

### 화면 2. 2분 컷 온보딩 (질문당 1화면)
```text
[ ████░░░░ ] 2 / 4

솔직하게 고르는 내 약점 2장
(빈칸을 채워줄 팀원이 매칭돼요)

[ 발표 울렁증 ]  [ 디자인 서툼 ]
[ 데이터 분석 약함 ]  [ 일정 관리 서툼 ]
[ 영문 자료 부담 ]  [ + 직접 입력 ]

---------------------------------
        [ 다음으로 (2/2) ]
```
- 긴 스크롤 설문 금지 → **진행률 바 + 칩 터치**로 게임처럼 빠르게 통과

### 화면 3. AI 분신 회의 중 (대기 화면)
- LLM 응답 시간(3~5초)이 지루하지 않도록 **실시간 중계 연출** 적용
- 순차 노출 문구 예시:
  1. *“온도와 시간대가 맞는 후보 12명을 찾았어요”*
  2. *“내 분신이 경영학도·디자이너와 첫 회의를 맞춰보는 중…”*
  3. *“합이 가장 잘 맞았던 2개 팀을 정리하고 있어요”*

### 화면 4. AI 모의회의 결과 카드 (핵심 화면)
```text
┌─────────────────────────────────────┐
│  조합 #1 · 4인 팀 · 온도 90° 일치    │
│                                     │
│  [퍼즐 보완 요약]                    │
│  • 내 약점(발표) ← B(경영) 강점으로 커버│
│  • B 약점(개발) ← 나+C(컴공) 강점으로 커버│
│                                     │
│  [AI 모의회의 하이라이트]             │
│  나(분신): "MVP 범위는 3기능으로 좁히죠"│
│  B(분신): "좋아요, 그럼 수익구조와 발표는│
│            제가 초안 잡을게요"        │
│  C(분신): "AI로 와이어프레임 오늘 뽑죠" │
│                                     │
│  💡 첫 회의 합의 포인트               │
│  AI 초안 활용 범위만 초반에 맞추면 최상│
│                                     │
│   [ 이 조합으로 만나볼래요 ]          │
│     (누가 먼저 눌렀는지 비공개예요)    │
└─────────────────────────────────────┘
```
- 한 화면에 **팀 조합 1개씩** 카드 스냅(좌우 탭 전환)으로 집중도 극대화

### 화면 5. 무거절 언락 & 팀 오픈
- 전원 수락 완료 시 축하 애니메이션과 함께 익명 라벨이 실제 이름·전공으로 전환
- 하단에 **오픈채팅방 만들기 / 참여 링크 복사** 및 **첫 회의 아젠다 3줄 자동 복사** 버튼 제공
