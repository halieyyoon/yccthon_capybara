# 06. UI 디자인 제안

> **디자인 핵심 한 줄**  
> **“내 목표 상태에 따라 분위기가 달라지는 퍼즐 프로필 + 깔끔한 CV 카드 + 한눈에 읽히는 모의회의 리포트”**

---

## 1. 핵심 디자인 컨셉: 상태에 따라 변하는 ‘퍼즐 프로필’

팀 논의를 반영해, 퍼즐을 고정된 아이콘이 아니라 **사용자의 현재 상태와 장점·약점을 표현하는 감성적 시각 요소**로 설계한다.

- **장점·약점 퍼즐 모양 (MBTI 매칭 매트릭스 참고)**:
  - 프로필 옆에 장점 카드(최대 16종 중 선택)와 약점 카드가 서로 맞물리는 도형/퍼즐 형태로 표시된다.
  - 팀 조합 화면에서는 4명의 퍼즐 조각이 하나로 합쳐지는 모습으로 보완 관계를 직관적으로 보여준다.
- **프로필 상태에 따른 테마 변화**:
  - `재미·경험 위주` 상태 → 둥근 모서리, 부드러운 파스텔 톤, 가볍고 경쾌한 분위기
  - `수상·취업 목표` 상태 → 각진 깔끔한 라인, 선명한 대비(딥 블루/차콜), 단단하고 신뢰감 있는 분위기
- **모바일 웹 최우선 (`390px` 기준)**: 에브리타임·카톡 링크로 들어와 앱 설치 없이 바로 작성·매칭 가능

## 2. 색상 & 글꼴 기준 초안

| 용도 | 컬러명 | HEX | 어디에 쓰나 |
|---|---|---|---|
| **전체 배경** | 따뜻한 미색 | `#FAF9F6` | 눈이 편한 기본 배경 |
| **카드 배경** | 순백 | `#FFFFFF` | 프로필·CV·모의회의 카드 + 얇은 테두리 `#E7E5E4` |
| **기본 글자** | 짙은 먹색 | `#18181B` | 제목·본문 |
| **보조 글자** | 차분한 회색 | `#71717A` | 안내 문구·메타 정보 |
| **수상·취업 모드 포인트** | 선명한 블루 | `#2563EB` | 단단한 진지 모드 & 핵심 버튼 |
| **재미·경험 모드 포인트** | 따뜻한 코랄/민트 | `#F97316` / `#10B981` | 경쾌한 경험 모드 퍼즐 포인트 |
| **약점 / 강점 퍼즐** | 연한 코랄 / 연한 민트 | `#FFF1F2` / `#ECFDF5` | 퍼즐 조각의 보완 관계 구분 |

- **글꼴**: `Pretendard` (한글) + `Inter` (숫자·영문)

## 3. 핵심 5개 화면 구성 제안

### 화면 1. 퍼즐 프로필 & 상태 전환
```text
┌─────────────────────────────────────┐
│  현재 상태: [ 🔥 수상·취업 ]  [ 🎈 재미 ] │
│                                     │
│   🧩 내 퍼즐 프로필 (자동 테마 반영)  │
│   [강점 퍼즐 2장]   [약점 퍼즐 2장]  │
│   • 빠른 구현       • 발표 울렁증    │
│   • AI 프롬프트     • 디자인 서툼    │
│                                     │
│   📅 주간 가능 시간표 (드래그 입력)   │
│   📄 내 CV 템플릿 보기 / 편집        │
└─────────────────────────────────────┘
```

### 화면 2. CV 템플릿 에디터
- 상단: **`링크드인 PDF / 이력서 올리고 자동 채우기`** 버튼
- 중단: 선택형 칩 + 한 줄 가이드 질문으로 경력·공모전 이력·사용 툴·AI 활용도를 빈칸 없이 완성
- 하단: **`PDF 저장`** / **`링크드인 복붙 요약 복사`** 버튼

### 화면 3. 1단계 클러스터 → 2단계 AI 아바타 결과 카드
```text
┌─────────────────────────────────────┐
│  조합 #1 · 4인 퍼즐 완성도 94%       │
│  [🧩 4인 퍼즐 맞물림 시각화 영역]    │
│                                     │
│  [추천 정기 회의 시간 (4인 전원 가능)] │
│  📅 화 19:00~21:00  ·  목 14:00~16:00│
│                                     │
│  [AI 아바타 모의회의 하이라이트]      │
│  나(아바타): "MVP는 3기능으로 좁히죠" │
│  B(아바타): "좋아요, 기획·발표 맡을게요"│
│  C(아바타): "AI로 시안 오늘 뽑아올게요"│
│                                     │
│  💡 첫 회의 합의 포인트               │
│  AI 초안 활용 범위만 초반에 맞추면 최상│
│                                     │
│  [ 바로 만나볼래요 ]                 │
│  [ ⏱️ 20분 파일럿 해커톤 먼저 해보기 ]│  ← 큰 해커톤/공모전일 때 강조 노출
└─────────────────────────────────────┘
```

### 화면 4. 3단계 파일럿 해커톤 (20분 미니 안건 해결방)
- 상단: **남은 시간 타이머 (`19:42`)** + 선택한 해커톤 안건 1줄 고정
- 중단: 4명이 함께 아이디어를 적는 간단한 공유 메모 + 실시간 채팅
- 종료 시: 각자 비공개로 **`이 팀으로 본선 갈래요`** / **`다음 기회에`** 선택

### 화면 5. 팀 확정 & 실명·CV 공개 화면
- 상호 수락 완료 시 4명의 퍼즐이 하나로 완성되는 연출 + 실명·학과·CV 템플릿 공개
- **4인 주간 시간표 겹침 표(When2Meet형)** + **오픈채팅방 연결** + **첫 회의 안건 복사** 제공
