# 06. UI 디자인 제안

> **디자인 핵심 한 줄**  
> **“링크드인보다 가볍고, 소개팅 앱보다 똑똑한 — 솔직한 대학생 프로젝트 라운지”**

---

## 1. 전체 디자인 느낌 & 원칙

- **스타일 키워드**: 잡지처럼 여백이 넓고 깔끔한 화면 · 카드 중심 구성 · 친근하고 위트 있는 말투
- **참고 감성**: Linear의 정돈된 글꼴 + Toss의 “한 화면에 질문 하나” 흐름 + 보드게임 카드의 직관성
- **모바일 웹 최우선 (`390px` 기준)**: 에브리타임·카톡 단톡방 링크를 눌러 앱 설치 없이 2분 안에 끝낼 수 있도록, 한 손 엄지 터치 기준으로 설계한다.

---

## 2. 색상 & 글꼴 기준 초안

### 컬러 팔레트
| 용도 | 컬러명 | HEX | 어디에 쓰나 |
|---|---|---|---|
| **전체 배경** | 따뜻한 미색 | `#FAF9F6` | 흰색보다 눈이 편한 페이지 배경 |
| **카드 배경** | 순백 | `#FFFFFF` | 카드·팝업 배경 + 얇은 테두리 `#E7E5E4` |
| **기본 글자** | 짙은 먹색 | `#18181B` | 제목·본문 |
| **보조 글자** | 차분한 회색 | `#71717A` | 부가 설명·안내 문구 |
| **핵심 버튼** | 선명한 블루 | `#2563EB` | 시작하기·만나볼래요 등 핵심 버튼과 선택 상태 |
| **약점 배지** | 연한 코랄 | `#FFF1F2` / `#E11D48` | 약점 카드 (부담 없는 파스텔 톤) |
| **강점 배지** | 연한 민트 | `#ECFDF5` / `#059669` | 강점 카드 (보완 관계 강조) |
| **온도·주의 박스** | 연한 앰버 | `#FFFBEB` / `#D97706` | 참여 온도, 첫 회의 합의 포인트 박스 |

### 글꼴 & 카드 형태
- **글꼴**: `Pretendard` (한글) + `Inter` (숫자·영문)
- **모서리**: 카드 둥글기 `16px` (`rounded-2xl`), 선택 버튼(칩) 완전 둥글게 (`rounded-full`)
- **그림자 절제**: 무거운 그림자 대신 얇은 테두리(`1px solid #E7E5E4`)와 충분한 여백으로 깔끔하게 구분

## 3. 핵심 5개 화면 구성 제안

### 화면 1. 첫 화면 & 학교 인증
- 상단: 서비스 이름 + 한 줄 소개 (*“스펙 대신 약점을 올리면, AI 분신이 팀플을 먼저 돌려봅니다”*)
- 중단: 실제 모의회의 결과 카드 예시 1장 (스크롤 없이 3초 만에 무슨 서비스인지 이해)
- 하단 고정 버튼: **`@yonsei.ac.kr`로 2분 만에 시작하기**

### 화면 2. 2분 컷 프로필 작성 (한 화면에 질문 하나)
```text
[ ████░░░░ ] 2 / 4

솔직하게 고르는 내 약점 2장
(빈칸을 채워줄 팀원이 매칭돼요)

[ 발표 울렁증 ]  [ 디자인 서툼 ]
[ 데이터 분석 약함 ]  [ 일정 관리 서툼 ]
[ 영문 자료 부담 ]  [ + 직접 입력 ]

---------------------------------
        [ 다음으로 (2/2) ]
```
- 긴 설문지 대신 **진행 막대 + 버튼 터치 + 주간 가능 시간표 드래그(When2Meet형)**로 빠르게 완료

### 화면 3. AI 분신 회의 중 (대기 화면)
- AI가 결과를 만드는 3~5초가 지루하지 않도록 **실시간 중계처럼 안내**
- 순차 문구 예시:
  1. *“온도와 가능 시간표가 맞는 후보 12명을 찾았어요”*
  2. *“내 분신이 경영학도·디자이너와 첫 회의를 맞춰보는 중…”*
  3. *“합이 가장 잘 맞았던 2개 팀을 정리하고 있어요”*

### 화면 4. AI 모의회의 결과 카드 (핵심 화면)
```text
┌─────────────────────────────────────┐
│  조합 #1 · 4인 팀 · 온도 90° 일치    │
│                                     │
│  [퍼즐 보완 요약]                    │
│  • 내 약점(발표) ← B(경영) 강점으로 커버│
│  • B 약점(개발) ← 나+C(컴공) 강점으로 커버│
│                                     │
│  [추천 정기 회의 시간 (4인 전원 가능)] │
│  📅 화 19:00~21:00  ·  목 14:00~16:00│
│                                     │
│  [AI 모의회의 하이라이트]             │
│  나(분신): "MVP 범위는 3기능으로 좁히죠"│
│  B(분신): "좋아요, 그럼 수익구조와 발표는│
│            제가 초안 잡을게요"        │
│  C(분신): "AI로 화면 시안 오늘 뽑죠"  │
│                                     │
│  💡 첫 회의 합의 포인트               │
│  AI 초안 활용 범위만 초반에 맞추면 최상│
│                                     │
│   [ 이 조합으로 만나볼래요 ]          │
│     (누가 먼저 눌렀는지 비공개예요)    │
└─────────────────────────────────────┘
```
- 한 화면에 **팀 조합 1개씩** 집중해서 보여주고, 좌우로 넘겨 다른 조합 확인

### 화면 5. 팀 확정 & 실명 공개 화면
- 서로 수락 완료 시 축하 화면과 함께 익명 닉네임이 실제 이름·학과로 전환
- **4인 주간 시간표 겹침 표(When2Meet형)**와 **정기 회의 추천 시간 TOP 3** 자동 표시 (바로 클릭 투표 가능)
- 하단에 **오픈채팅방 연결** 및 **첫 회의 안건 3줄 자동 복사** 버튼 배치
