# 02. 서비스 차별화

> **차별화 요약**  
> 게시판과 좌우 스와이프를 버리고, **약점 기반 프로필 → AI 분신 모의회의 → 무거절 일괄 매칭 + 정기 회의 시간 자동 추천**으로 팀 구하는 경험 자체를 바꾼다.

---

## 1. 기존 서비스와의 비교

| 구분 | 에브리타임 / 링커리어 | 링크드인 | **우리 서비스** |
|---|---|---|---|
| **핵심 입력** | 자유 모집글, 스펙 나열 | 경력·학력·이력서 | **약점·강점 카드, 참여 온도, 가능 시간표, AI 스타일, 협업 지뢰** |
| **찾는 방식** | 게시판 스크롤, 키워드 검색 | 인맥·채용 공고 검색 | **AI 분신이 먼저 모의회의 후 최적 4인 팀 제안** |
| **심리적 부담** | 지원·거절·읽씹 스트레스 | 취업 중심의 무거운 분위기 | **누가 먼저 눌렀는지 비공개(무거절 소집)** |
| **사람 적을 때** | 지원자 없으면 빈 게시판 | 재학생 활동량 낮음 | **미리 돌려보는 AI 방식 + 금요일 일괄 매칭으로 30명만 있어도 즉시 작동** |

---

## 2. 4가지 핵심 차별화 포인트

### ① 입력 방식의 역전: 스펙 자랑 → 솔직한 ‘약점 카드’ 퍼즐
- 잘하는 것을 억지로 포장하는 대신, **“내가 못 하는 것 2장 + 대신 해줄 수 있는 것 2장”**을 고르게 한다.
- 약점을 솔직하게 적을수록 그 빈칸을 메워줄 팀원을 만나는 구조라, 경력이 적은 저학년도 부담 없이 좋은 프로필을 완성한다.

### ② 매칭 경험의 혁신: 목록·스와이프 → ‘AI 분신 사전 모의회의’
- 사용자가 수십 명의 프로필을 읽는 대신, 각자의 성향·AI 스타일·협업 지뢰를 반영한 **AI 분신들이 먼저 6턴짜리 가상 첫 회의**를 돌려본다.
- 결과 화면에서는 숫자 점수 대신 **“이 4명이 만나면 첫 회의가 어떻게 흘러갈지” 4~5줄 요약**과 **첫 회의에서 맞춰볼 포인트 1줄**을 보여준다.
- 실시간으로 동시에 접속할 필요가 없기 때문에, 연세대 초기 사용자가 30~50명뿐인 첫날부터 빈 화면 없이 핵심 기능을 체험할 수 있다.

### ③ 캠퍼스 맞춤 결성 구조: ‘무거절 소집’ + ‘매주 금요일 일괄 매칭’ + ‘정기 회의 시간 자동 추천’
- 마음에 드는 조합을 눌러도 누가 먼저 눌렀는지 상대방에게 보이지 않으며, **서로 수락했을 때만 실명·전공·연락처가 공개**된다.
- 아무 때나 신청해 하염없이 기다리지 않도록 **매주 금요일 밤 10시에 그 주 신청자들을 한꺼번에 매칭해 동시 알림**을 보낸다. 다들 같은 시간에 앱을 열어 수락 속도와 팀 성사율이 크게 올라간다.
- **When2Meet형 정기 회의 시간 자동 추천**: 처음 입력한 주간 가능 시간표가 매칭에 바로 반영되며, 팀이 제안·확정되는 순간 **“이 4명이 매주 정기적으로 만나기 가장 좋은 시간 TOP 3”**를 자동 계산해 준다. 단톡방에서 따로 시간 조율 링크를 돌릴 필요가 없다.

### ④ 현실적인 연동과 따라 하기 어려운 경쟁력
- **링크드인 연동 제약의 현실적 해결**: 링크드인 공식 정책상 외부 앱이 경력을 양방향 자동 동기화하는 것은 불가능하다. 대신 **링크드인 PDF·이력서를 올리면 AI가 자동 입력**해 주고, **프로젝트가 끝나면 링크드인에 바로 붙여넣을 요약 문구**를 만들어 두 번 입력하는 불편을 없앤다.
- **시간이 갈수록 쌓이는 신뢰망**: 연세대에서 타 대학으로 확장할수록 **실제 프로젝트 완주 상호 확인 + 비공개 재협업 의사**가 쌓여, “내 이전 팀원이 함께 완주했던 검증된 팀원”을 추천하는 지인 신뢰망이 형성된다.
- **수익 모델의 자연스러운 결합**: 돈을 낸 개인 프로필을 상단에 띄우면 매칭 신뢰가 깨진다. 대신 공모전 주최 측이 원하는 조건(전공·기술·관심사)에 맞는 학생에게만 **자연스럽게 추천되는 맞춤형 공모전 광고**로 수익화한다.
