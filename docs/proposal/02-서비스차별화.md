# 02. 서비스 차별화

> **차별화 요약**  
> 게시판과 스와이프를 버리고, **약점 기반 입력 → AI 분신 모의회의 → 무거절 자동 결성**으로 팀 빌딩의 문법 자체를 바꾼다.

---

## 1. 기존 서비스와의 비교

| 구분 | 에브리타임 / 링커리어 | 링크드인 | **우리 서비스** |
|---|---|---|---|
| **핵심 입력** | 자유 글, 스펙 나열 | 경력·학력·이력서 | **약점·강점 카드, 참여 온도, AI 스타일, 협업 지뢰** |
| **탐색 방식** | 게시판 스크롤, 키워드 검색 | 인맥·채용 공고 탐색 | **AI 분신이 먼저 모의회의 후 최적 4인 팀 제안** |
| **심리적 부담** | 지원·거절·읽씹 스트레스 | 구직 중심의 무거운 분위기 | **선요청자 비공개 무거절 소집** |
| **초기 풀 대응** | 사람 적으면 빈 게시판 | 학생 활동량 낮음 | **비동기 AI 시뮬레이션으로 30명만 있어도 즉시 작동** |

---

## 2. 4가지 핵심 차별화 축

### ① 입력 방식의 역전: 스펙 자랑 → 솔직한 ‘약점 카드’ 퍼즐
- 잘하는 것을 포장하게 만드는 대신, **“내가 못 하는 것 2장 + 덮어줄 수 있는 것 2장”**을 꺼내게 한다.
- 솔직하게 약점을 적을수록 그 빈칸을 정확히 메워주는 팀원을 만나는 구조라, 초보자도 부담 없이 고품질 데이터를 입력한다.

### ② 매칭 경험의 혁신: 리스트·스와이프 → ‘AI 분신 사전 모의회의’
- 유저가 수십 명의 프로필을 읽는 대신, 각 유저의 성향·AI 스타일·지뢰를 주입한 **AI 분신들이 먼저 6턴짜리 가상 킥오프 회의**를 돌려본다.
- 결과 화면에서는 점수가 아니라 **“이 4명이 만나면 첫 회의가 어떻게 굴러갈지” 4~5줄 하이라이트**와 **사전 합의 포인트 1줄**을 제시한다.
- 실시간 동시접속자가 필요 없는 **비동기 방식**이므로, 연세대 초기 유저가 30~50명뿐인 첫날부터 빈 화면 없이 핵심 가치를 체감한다.

### ③ 캠퍼스 맞춤 결성 구조: ‘무거절 소집’ + ‘매주 금요일 일괄 매칭’ + ‘정기 회의 시간 자동 추천’
- 마음에 드는 조합을 눌러도 누가 먼저 눌렀는지 공개되지 않고, **상호 수락 시에만 실명·전공·연락처가 언락**된다.
- 매주 정해진 시각(예: 금요일 밤 10시)에 **일괄 매칭(주간 팀 드롭)**을 운영해 초기 유동성을 한 시점에 집중시키고 주기적 재방문을 만든다.
- **When2Meet형 정기 회의 시간 자동 추천**: 온보딩 때 입력한 주간 가능 시간표가 매칭 점수에 바로 반영되며, 팀이 제안·확정되는 순간 **“이 4명이 매주 정기적으로 만나기 좋은 시간 TOP 3”**를 자동 추천해 단톡방에서 따로 When2Meet을 돌리는 번거로움을 없앤다.

### ④ 현실적 연동과 장기 해자(Moat)
- **LinkedIn API 제약의 영리한 우회**: 불가능한 양방향 API 대신 `PDF/이력서 업로드 자동 파싱(입력)` + `프로젝트 완료 후 LinkedIn 복붙용 요약 자동 생성(출력)`으로 중복 입력 불편을 해소한다.
- **확장 시 복제 불가능한 데이터**: 연세대에서 시작해 타 대학으로 넓어질수록 **완주 상호 인증 + 비공개 재협업 의사 시그널**이 쌓여 ‘2촌 검증 협업 신뢰 그래프’가 장기 해자가 된다.
- **수익 모델의 자연스러운 결합**: 개인 프로필 유료 부스트(신뢰 훼손 위험) 대신, 공모전 주최사가 원하는 조건(전공·기술·관심사)에 맞는 유저에게만 추천하는 **고효율 타깃 네이티브 광고**로 연결한다.
