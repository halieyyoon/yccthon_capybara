# AI Agent 작업 지침서 — 규혁 (UX · 라우팅 · 상태관리 · 인터랙션 · 카피)

> **필독 기준 문서**: 루트의 [`SPEC.md`](../../SPEC.md) 및 [`docs/proposal/08-팀원매칭척도및설문설계.md`](../proposal/08-팀원매칭척도및설문설계.md)  
> 이 문서는 **규혁 담당 AI 에이전트**가 2분 핵심 온보딩 + 선택 심화 설문, 3단계 매칭 흐름, 정직한 설명 카피, 시연용 컨트롤을 빈틈없이 구현하도록 정리한 지침서입니다.

## 2. 핵심 UX & 카피 원칙 (`08번 문서` 정합)

1. **성향 설문 29문항 · 6단계 (v1.2)**:
   - 한 화면에 한 섹션, 문항마다 맞는 형식(원탭 카드·척도·칩)으로 답하고, 답할수록 내 조각이 완성됨
   - **A 일하는 방식 · B AI 쓰는 방식 · C 역할과 역량 · D 성격 · E 의견이 부딪힐 때 · F 함께하는 방식** — 모두 필수, 27차원이 전부 채워짐
   - 성격·갈등은 요인당 1문항 자체 작성이라 **점수에 쓰지 않고** AI 모의회의·대화 주제에만 씀 (`(i)` 안내)
   - 목표 4차원은 묻지 않고 **대회별 참여 온도**에서 참고값으로 만듦. 온도·주당 시간은 프로필/매칭에서 대회마다 정함
2. **과장 금지 & 근거 중심 카피**:
   - ❌ “궁합 정확도 94%!”, “검증된 심리검사 결과”
   - ✅ **“임시 가중치 기준 조합 지수”**, **“응답 근거: 모두 빠른 프로토타이핑 선호 · 디자인 역량 보완”**, **“AI 모의회의는 행동 예측이 아닌 사전 쟁점 확인용 가상 실험입니다”**
3. **무거절 심리 설계**: “거절당함” 알림·문구 전면 금지, 선요청자 비공개 문구 항상 병기
4. **0초 시연 진입**: 첫 화면에 `@yonsei.ac.kr` 입력 + **“데모 계정으로 1초 체험하기”** 버튼 제공

## 3. 상태 관리 (`src/store/useOndoStore.ts`)

`localStorage` (`ondo_mvp_state_v1`)에 영속 저장되는 스토어(Context 또는 Zustand)를 구현합니다.

- **상태**: `currentUser`, `selectedContestId`, `clusteredPoints`, `recommendedTeams`, `avatarMeetings`, `pilotStates`, `unlockedTeamIds`, `weeklyDropPreviewOpen`
- **핵심 액션**:
  - `initDemoUser()` — 연세대 시연용 데모 유저(27차원 전체 보유, 90°, 컴공 3학년) 1클릭 로드
  - `updateTemperatureMode(mode)` — 상태 3종 전환 시 퍼즐 테마 & 목표 참고값 동기화
  - `updateOptionalFeatures(patch)` — 성격 5·갈등 5 심화 설문 추후 입력/수정
  - `updateCv(patch)` — 5섹션 CV 업데이트
  - `runMatchingForContest(contestId)` — 혜원의 `runClusterAnalysis` + `recommendTeams` 호출 → 대규모(`scale === 'large'`)이면 1순위 팀 `/api/avatar-meeting` 자동 호출·캐싱
  - `unlockTeam(teamId)` — 무거절 상호 수락 연출(1.5초) 후 `status = 'UNLOCKED'`

## 4. 7개 페이지 상세 UX 흐름

### 1) `/` — 랜딩 & 로그인
- On-do 소개 + 미니 퍼즐 프리뷰 + `@yonsei.ac.kr` 입력 (`/onboarding` 이동)
- **`데모 계정으로 바로 둘러보기`** 버튼 (`initDemoUser()` → `/profile`)

### 2) `/onboarding` — 성향 설문 29문항 (v1.2)
- **① 내 조각 설문 (A~F 6단계, 모두 필수)**: A 일하는 방식(작업 방식 4) · B AI 쓰는 방식(AI 규범 3) · C 역할과 역량(희망 역할·역량 6·장점 2·약점 2) · D 성격(5) · E 의견이 부딪힐 때(갈등 5) · F 함께하는 방식(협업 지뢰 1~2·오프라인·밤샘)
- **② 결과 ‘내 조각이 나왔어요!’**: 16가지 조각 유형 + 딱 맞물리는 짝 + 포개지는 쌍둥이
- **③ CV로 이어짐**: 닉네임·전공·학년은 CV ‘기본 정보’에서 입력 (프로필 = 퍼즐 + CV, 건너뛰기 가능)
- 참여 온도·주당 시간은 대회마다 달라서 온보딩에서 묻지 않고 프로필/매칭에서 정함

### 3) `/profile` — 내 퍼즐 프로필 (+ Weekly Drop)
- 상단: **온도 상태 3종 실시간 전환 토글** → `PuzzleProfileCard` 디자인 변화 즉시 확인
- 중단: 내 퍼즐 카드 + 27차원 응답 완성도 배지 *(예: “17/27 완료 · 성격·갈등 추가 입력하기”)*
- 하단 1: **Weekly Drop (매주 금요일 밤 10시 자동 매칭 알림)** 토글 + **`[이번 주 드롭 미리보기]`** 모달
- 하단 2: **`내 CV 템플릿` (`/cv`)** + **`공모전 팀 찾기` (`/match`)**

### 4) `/cv` — CV 템플릿 에디터
- 상단: **PDF 업로드** + **`[샘플 링크드인 PDF로 자동 채워보기]`** → `/api/parse-cv` 호출
- 중단: 표준 5섹션 편집 폼 (경력 항목 추가/삭제)
- 하단: **`링크드인 복붙 요약 복사`** + **`PDF 저장 / 인쇄`** (`window.print()`)

### 5) `/match` — 공모전 선택 & 1·2단계 매칭
- 공모전 목록 (`소규모 · 바로 매칭` vs `대규모 · AI 아바타 + 파일럿 지원`)
- **1단계 영역**: `ClusterScatterPlot` (101명 27차원 Gower+PAM 2D 탐색 시각화 + *“합성 시드 100명 탐색 데모 · 2D 거리는 참고용”* 캡션)
- **추천 팀 카드 (`#1 / #2 / #3` 탭)**:
  - `TeamPuzzleMerge` + **응답 근거 태그(`evidenceTags`)** + **가장 큰 차이 쟁점(`biggestGapNote`)** + **`minMemberFit` 안내**
  - 결측이 있을 경우 `missingInfoNotice` 배지 표시
  - **소규모(`small`)**: **`[바로 만나볼래요]`** 단일 버튼
  - **대규모(`large`)**: **`AvatarMeetingCard`** (6턴 대화 + 합의안 + 미해결 쟁점 + 예상 역할 분담 + 팀원에게 확인할 질문) + 하단 2버튼: **`[바로 만나볼래요]`** / **`[20분 파일럿 해커톤 먼저 해보기]`** (`/pilot/[teamId]`)

### 6) `/pilot/[teamId]` — 3단계 20분 파일럿 해커톤
- 안건 3개 중 1개 선택 → `20:00` 타이머 + **`[시연용 30초 단축]`** + **`[종료 & 투표]`**
- 1페이지 공유 메모(문제/아이디어/역할) + AI 팀원 3명 실시간 채팅(`/api/pilot-chat`, `suggestedWorkspacePatch` 원클릭 반영 버튼 포함)
- 종료 시 비공개 투표 → 수락 시 `/team/[teamId]` 이동

### 7) `/team/[teamId]` — 팀 확정 & 실명·CV 언락
- 4인 퍼즐 합체 연출 + 익명 닉네임 → 실명·전공·학년 공개 + 멤버별 5섹션 CV 열람 모달
- **`오픈채팅 링크 복사`** + **`실제 첫 회의 확인 질문(questionsToAskTeam) 복사`** 버튼

## 5. 완료 체크리스트 (Acceptance Criteria)
- [ ] 온보딩 6단계 설문을 마치면 27차원이 모두 채워지고(성격·갈등은 점수 미사용), 결측이 있는 합성 시드 후보가 포함된 팀에는 `missingInfoNotice`가 정상 표시됨 *(v1.2 — 이전 기준 ‘Step 4 건너뛰기 시 null’을 대체)*
- [ ] UI 어디에도 “궁합 정확도 N%” 또는 “검증된 심리검사” 같은 과장 문구가 없음
- [ ] 데모 계정 1클릭 → 온도 전환 → CV 자동 채우기 → 대규모 매칭(101명 산점도 + AI 아바타) → 20분 파일럿 채팅 → 팀 언락까지 무중단 시연 가능
