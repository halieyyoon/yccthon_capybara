# 대학생 프로젝트 팀원 매칭 — MVP 코어 설계

> **한 줄 정의**  
> 스펙 대신 **약점·성향·가능 시간표**를 입력하면, 내 AI 분신이 먼저 가상 팀플을 돌려보고 가장 합이 좋은 4인 팀과 정기 회의 시간까지 추천해 주는 **무거절 팀 빌딩 서비스**

---

## 1. 핵심 조합

초기 연세대 참여자가 적을 때(50~200명)도 첫날부터 차별화를 체감할 수 있도록 **3가지 매칭 방식**을 코어로 묶었습니다.

1. **입력 — 약점 카드 퍼즐 매칭 + 가능 시간표** *(매칭 #4 · 기술 #1, #2)*  
   경력이 적어도 2분 만에 작성할 수 있고, 서로의 빈칸을 메우는 조합과 정기 회의 시간을 함께 계산합니다.

2. **매칭 — AI 분신 사전 모의회의** *(매칭 #1 · 기술 #2, #3)*  
   게시판과 좌우 스와이프를 없앱니다. 동시에 접속할 필요 없이 미리 돌려보는 방식이라, 초기 참여자가 적어도 첫날부터 결과 화면이 완성됩니다.

3. **결성 — 무거절 상호 소집 + 매주 금요일 일괄 매칭** *(매칭 #5 · 기술 #4)*  
   좁은 캠퍼스의 거절 스트레스를 없애고, 매주 금요일 밤 10시에 그 주 신청자들을 한꺼번에 매칭해 응답 속도와 팀 성사율을 높입니다.

---

## 2. 이용 흐름 (4단계)

```text
[1. 2분 프로필 작성] ──▶ [2. AI 분신 투입] ──▶ [3. 모의회의·회의시간 카드] ──▶ [4. 무거절 팀 확정]
```

### Step 1. 2분 컷 프로필 작성
- **학교 인증**: `@yonsei.ac.kr` 이메일 인증
- **경력 자동 채우기 (선택)**: 링크드인 PDF·이력서·GitHub 주소를 올리면 AI가 자동 입력 *(기술 #1)*
- **필수 입력 4가지**
  - **참여 온도 & 가능 시간표**: 진지(수상) ↔ 편함(경험), 주당 투입 시간 + **When2Meet처럼 드래그해서 고르는 주간 가능 시간표**
  - **AI 활용 스타일**: 짧은 실제 상황 질문 3개로 자동 분류 *(기술 #2)*
  - **약점 2장 + 강점 2장**: 예) 약점 `발표 울렁증` / 강점 `밤샘 백엔드 구현` *(매칭 #4)*
  - **협업할 때 절대 못 참는 행동 1~2개**: 예) `연락 두절`, `이해 없이 AI 복붙` *(기술 #2)*

### Step 2. 공모전 선택 → AI 분신 보내기
- 관심 공모전이나 자유 주제를 고르고 **“내 AI 분신 보내기”** 클릭 *(기술 #3)*
- 내 분신이 적합한 후보 조합(3~4인)과 짧은 가상 첫 회의를 진행 *(매칭 #1)*

### Step 3. 결과 카드 확인
사람 목록 대신 **가장 합이 좋았던 팀 조합 2~3개**가 카드로 도착합니다.
- **팀 퍼즐 요약**: 누가 누구의 약점을 메워주는지 한눈에 정리 *(매칭 #4)*
- **추천 정기 회의 시간 TOP 3**: 4명의 가능 시간표가 겹치는 시간대 자동 추천 *(When2Meet형)*
- **모의회의 하이라이트**: 실제 첫 회의 분위기 4~5줄 미리보기 *(매칭 #1)*
- **첫 회의 합의 포인트**: 예) *“목표·시간 일치 / AI 초안 활용 범위만 첫 회의에서 합의 권장”* *(기술 #2)*

### Step 4. 무거절 소집 → 팀 확정
- 마음에 드는 조합에 **“만나볼래요”** 클릭 (누가 먼저 눌렀는지 비공개) *(매칭 #5)*
- 팀원들에게 알림 발송 → 서로 수락 시 실명·학과·상세 프로필 공개
- 팀 확정 화면에서 **4인 시간표 겹침 표(When2Meet형)**를 바로 확인하고, 카카오톡 오픈채팅·디스코드로 연결

---

## 3. 단계별 로드맵 (인덱스 연계)

### MVP (v1) — 핵심 기능 검증
- **매칭 #4** 약점 카드 퍼즐 매칭 *(작성 부담 제거 + 정기 회의 시간표 연동)*
- **매칭 #1** AI 분신 사전 모의회의 *(핵심 차별화)*
- **매칭 #5** 무거절 상호 소집 / 매주 금요일 일괄 매칭 *(거절 부담 해소 + 응답 집중)*
- **기술 #1** PDF 자동 입력 & 완료 후 링크드인 복붙 요약 *(API 제약 우회)*
- **기술 #2** 협업 지뢰 회피 & 팀 조합 점수 계산 *(1단계 후보 추리기 + 합의 포인트)*

### v2 — 커뮤니티 & 신뢰 데이터 확장
- **매칭 #3** 스펙 가리고 아이디어로 먼저 매칭 *(공모전별 참여자가 늘어난 뒤 추가)*
- **매칭 #6** 15분 가벼운 질문 → 팀 전환 *(상시 방문자가 쌓인 뒤 추가)*
- **매칭 #8** 온도·시간표 지도 화면 *(에브리타임 시간표 이미지 연동)*
- **기술 #4** 지인 검증 신뢰망 *(1기 완주 데이터가 쌓인 뒤 가동)*

### v3 — 타 대학 확장 & 수익화
- **매칭 #2** 20분 익명 체험 협업 *(동시 접속자가 충분할 때 라이브 이벤트로 운영)*
- **매칭 #7** 1명씩 릴레이로 팀 완성 *(기존 2~3인 팀의 마지막 1명 충원 모드)*
- **기술 #3** 맞춤형 공모전 추천 광고 *(타 대학 확장 후 본격 수익화)*

## 4. 기술 구조 & 비용 통제

AI 모의회의를 전체 조합에 돌리면 느리고 비싸지므로 **2단계**로 분리합니다.

1. **1단계 — 빠른 후보 추리기 (비용 0원)**  
   DB에서 점수를 계산해 상위 2~3개 조합과 4인 공통 가능 시간대만 먼저 뽑습니다.  
   `점수 = 온도 일치 + 가능 시간표 겹침 + 약점↔강점 보완 − 협업 지뢰 충돌`

2. **2단계 — AI 가상 첫 회의 생성 (조합당 1회 호출)**  
   AI를 여러 번 부르지 않고, **정해진 형식으로 1번만 호출**해 4인 가상 회의(6턴)·요약·합의 포인트를 한 번에 만듭니다. 경량 모델(Gemini Flash 등) 기준 조합당 몇 원 수준이며 저장해 재사용합니다.

### 권장 MVP 스택
- **화면(Frontend)**: Next.js *(모바일 웹 우선 — 에브리타임·단톡방 링크 유입)*
- **DB & 인증**: Supabase *(PostgreSQL + 학교 이메일 인증 + 권한 잠금)*
- **AI**: 경량 LLM API + 이력서 PDF 읽기
- **채팅**: 자체 개발 생략, 팀 확정 시 카카오톡·디스코드 연결
