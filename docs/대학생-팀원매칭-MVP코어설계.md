# 대학생 프로젝트 팀원 매칭 — MVP 코어 설계

> **한 줄 정의**  
> 스펙 대신 **약점·성향·AI 활용 방식**을 입력하면, 내 AI 분신이 먼저 가상 팀플을 돌려보고 가장 합이 좋은 4인 팀과 모의회의 하이라이트를 데려다주는 **무거절 팀 빌딩 서비스**

---

## 1. 핵심 조합

초기 연세대 풀(50~200명)에서도 첫날부터 차별화를 체감할 수 있도록 **3가지 매칭 방식**을 코어로 묶었습니다.

1. **입력 — 약점 카드 퍼즐 매칭** *(매칭 #4 · 기술 #1, #2)*  
   경력이 적어도 2분 만에 작성할 수 있고, 서로의 빈칸을 메우는 조합 데이터를 만듭니다.

2. **매칭 — AI 분신 사전 모의회의** *(매칭 #1 · 기술 #2, #3)*  
   리스트·스와이프를 없앱니다. 비동기로 돌아가므로 초기 유저가 적어도 첫날부터 결과 화면이 완성됩니다.

3. **결성 — 무거절 상호 소집 + 주간 드롭** *(매칭 #5 · 기술 #4)*  
   좁은 캠퍼스의 거절 스트레스를 없애고, 주 1회(예: 금요일 밤) 유동성을 모아 매칭 성공률을 높입니다.

---

## 2. 유저 흐름 (4단계)

```text
[1. 2분 온보딩] ──▶ [2. AI 분신 투입] ──▶ [3. 모의회의 카드 확인] ──▶ [4. 무거절 팀 오픈]
```

### Step 1. 2분 컷 온보딩
- **학교 인증**: `@yonsei.ac.kr` 이메일 인증
- **경력 자동 채우기 (선택)**: LinkedIn PDF·이력서·GitHub 업로드 시 AI가 자동 입력 *(기술 #1)*
- **필수 입력 4가지**
  - **참여 온도 & 시간**: 진지(수상) ↔ 가볍게(경험), 주당 투입 시간
  - **AI 활용 스타일**: 짧은 상황 질문 3개로 자동 분류 *(기술 #2)*
  - **약점 2장 + 강점 2장**: 예) 약점 `발표 울렁증` / 강점 `밤샘 백엔드 구현` *(매칭 #4)*
  - **협업 지뢰 1~2개**: 예) `연락 두절`, `이해 없이 AI 복붙` *(기술 #2)*

### Step 2. 공모전 선택 → AI 분신 보내기
- 관심 공모전이나 자유 주제를 선택하고 **“내 AI 분신 보내기”** 클릭 *(기술 #3)*
- 백그라운드에서 내 분신이 적합한 후보 조합(3~4인)과 짧은 가상 킥오프 회의를 진행 *(매칭 #1)*

### Step 3. 결과 카드 확인
사람 목록 대신 **가장 합이 좋았던 팀 조합 2~3개**가 카드로 도착합니다.
- **팀 퍼즐 요약**: 누가 누구의 약점을 덮어주는지 시각화 *(매칭 #4)*
- **모의회의 하이라이트**: 실제 첫 회의 분위기 4~5줄 미리보기 *(매칭 #1)*
- **사전 합의 포인트**: 예) *“목표·시간 일치 / AI 초안 활용 범위만 첫 회의에서 합의 권장”* *(기술 #2)*

### Step 4. 무거절 소집 → 팀 오픈
- 마음에 드는 조합에 **“만나볼래요”** 클릭 (누가 먼저 눌렀는지 비공개) *(매칭 #5)*
- 멤버들에게 알림 발송 → 수락 시 이름·전공·프로필 언락
- 초기에는 자체 메신저 대신 카카오톡 오픈채팅·디스코드로 바로 연결

## 3. 단계별 로드맵 (인덱스 연계)

### MVP (v1) — 코어 검증
- **매칭 #4** 약점 카드 퍼즐 매칭 *(온보딩 진입장벽 제거)*
- **매칭 #1** AI 분신 사전 모의회의 *(핵심 차별화)*
- **매칭 #5** 무거절 상호 소집 / 주간 드롭 *(거절 부담 해소 + 유동성 집중)*
- **기술 #1** PDF 자동 파싱 & 완료 후 LinkedIn 복붙 요약 *(API 제약 우회)*
- **기술 #2** 지뢰 필터 & 팀 조합 스코어링 *(1차 후보 추출 + 합의 포인트)*

### v2 — 커뮤니티 & 신뢰 데이터 확장
- **매칭 #3** 스펙 블라인드 생각 충돌 *(공모전 주제 풀이 커진 뒤 추가)*
- **매칭 #6** 15분 퀘스트 → 팀 승격 *(상시 활성 유저 확보 후 추가)*
- **매칭 #8** 은하계 & 시간표 오버레이 맵 *(에브리타임 시간표 연동)*
- **기술 #4** 협업 신뢰 그래프 *(1기 완주 데이터 축적 후 가동)*

### v3 — 타대 확장 & 수익화
- **매칭 #2** 20분 익명 시식 협업 *(동시접속 확보 후 라이브 이벤트로 운영)*
- **매칭 #7** 릴레이 소환식 팀 빌딩 *(2~3인 팀의 마지막 1명 충원 모드)*
- **기술 #3** 공모전 타깃 네이티브 광고 *(타대 인재 풀 확보 후 본격 수익화)*

## 4. 기술 구조 & 비용 통제

AI 모의회의를 전체 조합에 돌리면 느리고 비싸지므로 **2단계 파이프라인**으로 분리합니다.

1. **1단계 — 초고속 후보 추출 (비용 0원)**  
   DB 쿼리와 점수 계산으로 상위 2~3개 조합만 먼저 선정합니다.  
   `점수 = 온도 일치 + 시간 겹침 + 약점↔강점 보완 − 지뢰 충돌`

2. **2단계 — LLM 가상 킥오프 생성 (조합당 1회 호출)**  
   에이전트를 따로 돌리지 않고, **Structured JSON 호출 1번**으로 4인 가상 회의(6턴)·하이라이트·합의 포인트를 한 번에 생성합니다. 경량 모델(Gemini Flash / GPT-4o-mini급) 기준 조합당 수십 원 이하이며 캐싱으로 재사용합니다.

### 권장 MVP 스택
- **Frontend**: Next.js *(모바일 웹 우선 — 에브리타임·단톡방 유입 최적화)*
- **Backend / DB**: Supabase *(PostgreSQL + `pgvector` + 학교 이메일 Auth)* 또는 Cloudflare Workers + D1
- **AI**: 경량 LLM API *(Structured Output)* + PDF 텍스트 파싱
- **채팅**: 자체 개발 생략, 팀 확정 시 카카오톡·디스코드 연동
