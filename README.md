## 2. “약점·빈칸을 채우는 퍼즐” — 약점 카드 강조

- **빈칸 (Binkan)**  
  내 약점(빈칸)을 채워줄 팀원을 찾는다는 뜻. 한글 2글자로 짧고 캠퍼스 입에 착 붙음.  
  *“나 이번에 빈칸에서 디자이너 구했어”*

- **오프셋 (Offset)**  
  한 사람의 약점을 다른 사람의 강점으로 상쇄(Offset)하는 조합. 디자인·공학 계열에서 감도 높음.

- **미싱 (Missing)**  
  우리 팀에 빠진 마지막 퍼즐 조각(Missing Piece). 짧고 호기심을 끄는 이름.

- **틈새 (Teumsae)**  
  서로의 빈틈을 메워주는 4인 조합. 친근하고 솔직한 무드.

## 3. “진지 vs 편함 · 합(Chemistry)” — 온도와 리듬 강조

- **몇도 (Myeotdo)**  
  참여 온도(수상 90° vs 경험 36.5°)를 그대로 브랜드화. 일상 대화가 곧 홍보가 됨.  
  *“너 이번 공모전 몇 도야?”*

- **템포 (Tempo)**  
  진지함·마감 속도·주당 투입 시간까지 한 단어로 설명. *“같은 템포로 달릴 팀원”*

- **합 (Hab)**  
  한국 대학생이 팀플에서 가장 자주 쓰는 말(“합이 맞다”). 1글자 로고·앱 아이콘 임팩트 강함.

- **결 (Gyeol)**  
  스펙보다 “결이 맞는 사람”. 차분하고 세련된 에디토리얼 톤에 적합.

## 4. “공모전·팀 빌딩 이중 의미” — 전국 확장·브랜드형

- **드래프트 (Draft)**  
  ① 스포츠 팀 드래프트(팀 구성) ② 프로젝트 초안(Draft)의 이중 의미. 공모전·해커톤과 궁합 최상.  
  *“이번 주 금요일 드래프트 넣었어?”*

- **캐스트 (Cast)**  
  영화 캐스팅처럼 역할과 케미에 딱 맞는 4명을 조합해 준다는 느낌.

- **니트 (Knit)**  
  서로 다른 전공·성향을 촘촘하게 엮어 하나의 팀을 짠다는 따뜻한 미니멀 감성.

# VKU 인터뷰 후보 (2026-11-20)

목적: 베트남 공공 입찰 알림(트랙 1)에 돈을 낼 사람이 있는지 확인하기 위한 인터뷰 대상.
기준: 실제로 베트남 공공 입찰 정보를 찾는 일을 하는 사람. 개인 휴대폰 번호는 적지 않았다.

## 먼저 알아둘 것: 한국 기업은 베트남 공공사업을 어떻게 따나
조사하면서 확인한 사실이다. 트랙 1 상품 설계에 바로 영향을 준다.
- **한국 건설사가 딴 베트남 공공 공사는 대부분 ODA 재원이다.**
  - 동부건설 미안~까오랑 도로(약 2,166억 원): 베트남 건설부 발주, 수출입은행 EDCF와 베트남 정부 재원.
  - 일성건설 닌꾸엉교(약 252억 원): 건설부 산하 탕롱 사업관리단 발주, EDCF 재원. 일성건설의 베트남 다섯 번째 ODA 인프라 수주다.
- 수출입은행은 매년 EDCF 전략설명회에서 그해 **발주 예정 사업 목록**을 공개한다. 2025년에는 약 40건, 약 4조 원 규모의 입찰을 예정했다.
- 베트남 정부조달은 CPTPP 이후 일부가 외국 기업에 개방됐다. 다만 기준 금액이 높고(중앙기관 물품 약 200만 SDR부터), 오프셋 요구(조달액의 30~40%까지 현지 생산, 합작, 기술이전)가 있다. 현지 사업장이 없으면 합작, 하도급, 현지 대리인이 필요하다. 행정 문서는 대부분 베트남어로만 제공된다(베트남 상공부 산하 기관 2020년 보고서 기준).
- 전력 쪽은 EVN(베트남전력공사)이 큰 발주처다. LS에코에너지는 EVN에 초고압 케이블(약 454억 원)을 공급했다.

시사점: 트랙 1의 진짜 수요는 "VNEPS의 모든 공고"보다 **"ODA 재원 사업과 EVN 같은 대형 발주처의 입찰"**에 있을 수 있다. 인터뷰로 확인할 것.

# 대학생 프로젝트 팀원 매칭 커뮤니티 — 기술적 차별화 전략

## 배경 및 핵심 문제의식
기존 대학생 팀원 매칭 플랫폼(에브리타임, 링커리어, 렛플, 비긴메이트 등)은 대부분 **정적인 모집 게시판 + 자기신고형 프로필**에 머물러 있어 초기 이탈이 빠르고 매칭 신뢰도가 낮다.

이번 구상의 핵심 강점인 **AI 활용도·참여 온도(진지 vs 편함)·협업 지뢰(정 떨어지는 행동)·연세대 시작 후 타대 확장**을 실제 기술적 해자(Moat)로 발전시키기 위한 5가지 차별화 방향을 정리한다.

---

## 1. 링크드인 연동의 현실적 대안: 멀티소스 자동 프로필 빌더

### 기술적 제약 확인
- **LinkedIn 공식 API**는 파트너십 승인 없이는 개인의 경력·프로젝트를 외부 서비스에서 자유롭게 읽고 쓰는 양방향 동기화를 허용하지 않는다(일반 OAuth로는 이름·이메일·프로필 사진 등 기본 정보만 조회 가능).

### 차별화 구현 방안
- **입력 마찰 제거 (Multi-source Ingestion Pipeline)**
  - LinkedIn의 `PDF로 저장` 파일, 노션 포트폴리오, 기존 공모전 발표자료(PDF/PPT), GitHub 링크를 업로드하면 LLM 구조화 파이프라인이 경력·역할·기술 스택·사용 툴을 자동 추출해 프로필 템플릿 초안을 채운다.
  - 활동 이력이 적은 저학년·초보자는 짧은 대화형 Q&A를 통해 초안을 자동 생성한다.
- **역방향 내보내기 (Export for LinkedIn)**
  - 플랫폼에서 공모전·프로젝트를 완료하면 LinkedIn 경력/프로젝트 항목에 바로 붙여넣을 수 있는 국·영문 요약본과 **활동 검증 링크(Verified Page)**를 자동 생성해, API 제약 없이 중복 입력 불편을 해소한다.
- **증거 기반 프로필 (Proof of Work)**
  - GitHub 저장소 등을 연동해 단순 키워드 나열(“Python 가능”)이 아니라 최근 활동성, 실제 기여 비율, 주요 사용 라이브러리 등 검증 가능한 신호를 프로필에 반영한다.

---

## 2. 정적 설문을 넘어선 협업 궁합·지뢰 회피 매칭 엔진

**AI 활용도 / 참여 온도 / 정 떨어지는 행동**은 단순 체크박스로 두면 누구나 좋게만 작성해 변별력이 떨어진다. 이를 정교한 매칭 모델로 구조화한다.

- **시나리오 기반 성향 벡터화 (Situational Profiling)**
  - “AI 의존도: 상/중/하” 대신 실제 협업 상황 질문 3~5개(예: *“마감 전날 AI가 짠 코드가 돌아가긴 하는데 이해는 못 했을 때?”*, *“회의 전 아이디어 초안을 ChatGPT로만 뽑아온 팀원을 보면?”*)에 대한 응답으로 **실제 협업 스타일 벡터**를 생성한다.
- **Deal-breaker(지뢰) 자동 필터링**
  - 서술형으로 입력한 “협업 시 정 떨어지는 행동”을 LLM으로 정규화·임베딩(예: `연락 두절`, `출처 없는 AI 복붙`, `역할 떠넘기기`, `마감 직전 수정`)한다.
  - 한쪽이 극도로 기피하는 행동과 상대의 작업 스타일이 충돌할 경우 매칭 순위를 낮추거나 사전 합의 포인트로 안내한다.
- **개인 검색이 아닌 팀 조합 최적화 (Team Composition Engine)**
  - 기존 플랫폼의 “팀원 1명 검색”을 넘어, 현재 팀원들의 프로필을 묶어 **역량 보완성(부족한 직군·도메인)**과 **온도·리듬 일치성(목표 강도, 주당 투입 시간, 선호 작업 시간대, AI 활용 철학)**을 함께 계산한다.
  - 단순 점수 대신 **설명 가능한 매칭 근거**를 제공한다.
    - 예: *“목표 온도(수상 목표)·주당 15시간 일치 + 현재 팀에 없는 데이터 분석 역량 보완 / 참고: AI 초안 활용 방식은 사전 합의 권장”*

---

## 3. 공모전 공고 파싱 + 타깃 매칭·광고 모델의 기술적 결합

광고 수익 모델을 단순 배너가 아니라 **매칭 엔진의 일부**로 결합해 사용자 만족도와 광고 효율을 동시에 높인다.

- **공모전 공고 멀티모달 자동 구조화**
  - 주요 공모전·해커톤 포스터(이미지/PDF)와 요강을 수집·파싱해 `도메인`, `필요 직군 조합`, `심사 기준`, `예상 소요 기간`을 자동 추출한다.
- **공모전 기준 원클릭 팀원 추천**
  - 사용자가 관심 공모전을 선택하면 해당 대회 심사 기준과 도메인에 맞는 타 전공·타 대학 후보군을 자동 추천한다.
- **고효율 네이티브 광고**
  - 공모전 주최 측이 원하는 조건(예: *AI 구현 가능 + 금융/경영 전공 관심*)에 맞는 사용자에게만 해당 공모전을 추천하는 타깃팅 엔진으로 광고 단가를 높인다.
- **수익 모델 설계 시 주의점**
  - **유료 프로필 우선 노출**은 매칭 알고리즘 신뢰도를 떨어뜨릴 위험이 크다.
  - 개인 프로필 부스트보다는 **공모전 주최사 타깃 홍보 / 팀 모집 공고 상단 노출**로 수익화하고, 유료 노출은 명확히 구분 표시하는 편이 안전하다.

---

## 4. 확장 시 진짜 해자가 되는 협업 신뢰 그래프 (Trust Graph)

연세대에서 시작해 타 대학으로 확장할 때, UI는 쉽게 복제되지만 **축적된 협업 신뢰 데이터**는 복제할 수 없다.

- **학교 이메일 인증 + 프로젝트 완주 상호 인증**
  - 대학 이메일(`@yonsei.ac.kr` 등)로 신뢰 기반을 확보하고, 프로젝트 종료 후 팀원 간 상호 확인(Mutual Verification)을 통해 실제 완주 이력을 기록한다.
- **독성 없는 평판 시스템 설계**
  - 공개 별점이나 부정적 자유 리뷰는 명예훼손 분쟁과 커뮤니티 이탈을 유발한다. 대신 아래 두 가지로 분리해 축적한다.
    1. **공개용 긍정 강점 태그**: *마감 준수, AI 툴 활용 능숙, 발표 강점* 등
    2. **비공개 매칭 시그널**: *“이 사람과 다음 프로젝트도 함께하고 싶은가?”* — 외부 미공개, 내부 매칭 신뢰 점수에만 반영
- **2촌 검증 인재 추천**
  - 협업 이력이 그래프로 쌓이면 *“나와 함께 프로젝트를 완주했던 팀원이 추천한 타 대학 디자이너”*처럼 링크드인의 1·2촌 구조를 대학생 프로젝트 검증망으로 구현할 수 있다.

---

## 5. 오버엔지니어링 방지: 단계별 구현 로드맵

초기 구현 부담을 줄이기 위해 연세대 MVP부터 단계적으로 기술을 고도화한다.

| 단계 | 목표 | 핵심 기술 스택 / 구현 범위 |
|---|---|---|
| **1단계 (연세대 MVP)** | 빠른 검증 & 초기 인재 풀 확보 | 학교 이메일 인증, PDF/이력서 업로드 → LLM 프로필 자동 채우기, 구조화 필터(온도·시간·AI 활용도) + **자연어 팀원 검색**(예: *"진지하게 핀테크 공모전 나갈 디자이너, 주 10시간"*) |
| **2단계 (매칭 고도화)** | 매칭 품질 차별화 | 시나리오 기반 성향 임베딩, Deal-breaker 충돌 감지, 팀 단위 부족 역량 추천, 프로젝트 완료 후 상호 인증 + LinkedIn 복붙용 요약 자동 생성 |
| **3단계 (타대 확장 & 수익화)** | 크로스전공 네트워크 & 광고 | 공모전 공고 자동 크롤링/파싱 파이프라인, 2촌 협업 신뢰 그래프, 공모전 주최사 타깃 추천 광고 엔진 |

---

## 기술 설계 전 먼저 결정할 사항
1. **초기 타깃의 중심**: 개발·IT 해커톤(GitHub/기술스택 중심)부터 잡을지, 경영·마케팅·기획 공모전(문서/PPT/도메인 중심)까지 처음부터 열지에 따라 자동 프로필 파싱과 역량 검증 방식이 달라진다.
2. **매칭 UX 비중**: 사용자가 직접 검색·연락하는 **탐색형(마켓플레이스)** 중심인지, 공모전을 고르면 시스템이 팀 조합을 제안하는 **추천형(매칭 엔진)** 중심인지에 따라 초기 백엔드·AI 투자 우선순위가 달라진다.

# 대학생 프로젝트 팀원 매칭 — 기존 문법을 벗어난 8가지 팀 구성·매칭 방식

## 문제의식
기존 리스트 탐색(에브리타임·링커리어)과 스와이프(틴더)는 **“물건 1개 고르기”**에 최적화된 UI다. 반면 프로젝트 팀 빌딩은 **3~4명의 합(Chemistry), 시간 리듬, 역량 결핍을 맞추는 일**이며, 스펙 비교 중심의 구조에서는 작성 부담·거절 스트레스·실전 부조화가 반복된다.

기존 형식에 구애받지 않고 팀을 구성·매칭할 수 있는 8가지 대안을 정리한다.

---

## 1. AI 분신 사전 모의회의 (Agent-to-Agent Simulation)
> **“내가 직접 찾지 않고, 내 AI 분신들이 먼저 팀플을 돌려본다”**

- **방식**: 각 사용자의 프로필·협업 성향·AI 활용도·지뢰 포인트를 반영한 개인 AI 에이전트가 백그라운드에서 다른 사용자들의 AI 에이전트와 **가상 킥오프 회의**를 수십 번 시뮬레이션한다.
- **결과 화면**: 사람 리스트 대신 **“가장 회의가 잘 풀렸던 가상 팀 조합 3개 + 5줄짜리 모의회의 하이라이트”**를 제시한다.
- **매칭**: 모의대화록에서 합이 잘 맞아 보이는 조합을 선택해 실제 사람들에게 소집 요청을 보낸다.
- **강점**: 검색·스와이프 피로가 거의 없고, “내 분신이 찾아온 팀”이라는 콘셉트 자체로 캠퍼스 내 바이럴 효과가 크다.

---

## 2. 20분 익명 ‘시식 협업’ (Micro-Sprint Chemistry)
> **“이력서 100줄보다, 딱 20분 같이 일해보면 답 나온다”**

- **방식**: 전공·학번·스펙을 가린 채 참여 온도(진지/가벼움)가 비슷한 4명이 랜덤 방에 모여 **20분짜리 미니 미션**(예: 실제 공모전 주제 1개로 1페이지 아이디어 구조 짜기)을 실시간 채팅/화이트보드에서 함께 수행한다.
- **매칭**: 종료 후 각자 **“이 사람들과 본선까지 갈래요”**를 비공개 투표하고, 상호 선택한 사람들끼리만 실제 프로필이 공개되며 팀이 확정된다.
- **강점**: “정 떨어지는 행동”을 설문이 아니라 20분 만에 직접 체감하며, 실제 소통 속도·AI 활용 태도가 즉시 드러난다.

---

## 3. 스펙 블라인드 ‘생각 충돌’ 매칭 (Idea-First Collision)
> **“사람이 아니라, 문제에 대한 ‘관점’이 먼저 매칭된다”**

- **방식**: 공모전 주제가 열리면 스펙 대신 **“이 주제라면 나는 이렇게 풀겠다”는 3줄 관점·스케치·질문**을 익명으로 제출한다.
- **매칭**: 시스템이 프로필이 아니라 **서로 날카롭게 보완되는 관점끼리** 연결한다.
  - 예: *“당신은 기술 해결책을 냈고, 익명 #42는 정확히 그 기술이 필요한 시장 문제를 짚었습니다. 대화해보시겠어요?”*
- **강점**: 저학년이나 경력이 적은 학생도 날카로운 관점 하나로 에이스 팀에 합류할 수 있고, 타 전공(경영·인문·공학·디자인)이 자연스럽게 섞인다.

---

## 4. ‘약점 카드’ 퍼즐 매칭 (Flaw-Fit Puzzle)
> **“잘하는 걸 자랑하지 말고, 못 하는 걸 솔직히 꺼내놓는 매칭”**

- **방식**: 자기 자랑 프로필 대신 **내 약점 카드 2장 + 내가 덮어줄 수 있는 강점 카드 2장**만 제출한다.
  - 예: `[약점: 발표 울렁증, 디자인 감각 제로]` / `[강점: 밤새 백엔드 구현, AI 프롬프트 자동화]`
- **매칭**: 시스템이 **서로의 약점을 정확히 덮어주는 4명**을 묶어 하나의 완성된 퍼즐 카드로 제안한다.
- **강점**: “내세울 경력이 없다”는 대학생의 심리적 장벽을 역전시켜, 솔직할수록 더 좋은 팀을 만나는 구조를 만든다.

---

## 5. 주간 일괄 ‘무거절’ 자동 배정 (Gale-Shapley / Weekly Drop)
> **“거절하기 민망하고, 거절당하기 싫은 캠퍼스 심리를 없앤다”**

- **방식**: 좁은 대학 커뮤니티에서 발생하는 거절·읽씹 스트레스를 없애기 위해, 상시 DM 대신 **매주 특정 시각(예: 수요일 밤 10시)**에 안정 매칭 알고리즘(Gale-Shapley 변형)으로 해당 주간 신청자들을 최적의 4인 팀으로 일괄 결성해 발표한다.
- **매칭**: 목표 온도·시간표·필요 직군·비공개 선호 조건만 걸어두고 기다리며, 미매칭 시에도 “누구에게 거절당했다”는 알림이 없어 감정 소모가 없다.
- **강점**: 구인/구직 면접의 피로를 없애고, “수요일 밤 10시 팀 드롭(Drop)”이라는 주기적 리텐션 포인트를 만든다.

---

## 6. 가벼운 ‘15분 퀘스트’ → 팀 승격 (Micro-Help to Team)
> **“처음부터 ‘2달 같이 하자’고 하지 말고, 15분짜리 질문에서 시작한다”**

- **방식**: “공모전 팀원 구함” 대신 **“이것만 15분 같이 뚫어볼 사람”** 보드를 운영한다.
  - 예: *“소상공인 아이디어가 있는데 크롤링 가능 여부만 15분 봐줄 컴공?”*, *“장표 3장만 디자인 피드백 줄 사람?”*
- **매칭**: 가볍게 도와주며 대화하다가 합이 맞으면 채팅방 상단의 **“이대로 프로젝트 팀 결성하기”** 버튼으로 즉시 팀을 전환한다.
- **강점**: 장기 프로젝트 약속의 부담을 크게 낮추어 자연스러운 스파크에서 팀이 탄생한다.

---

## 7. 릴레이 소환식 ‘진화형 팀 빌딩’ (Chain Summon)
> **“팀장 1명이 3명을 면접 보는 게 아니라, 팀이 1명씩 합체하며 진화한다”**

- **방식**: 4명을 한 번에 모집하지 않고 단계적으로 결성한다.
  1. 내가 1명(예: 디자이너)과 먼저 2인 결성
  2. 시스템이 **우리 둘의 합쳐진 성향·시간표·빈 역량을 실시간 재계산**해 3번째 멤버 후보 제안
  3. 3명이 함께 4번째 마지막 퍼즐을 소환
- **강점**: 팀장 중심의 수직 구조를 깨고 수평적으로 팀이 형성되며, 멤버가 늘어날수록 추천 풀이 살아 움직이는 재미를 준다.

---

## 8. 은하계 & 시간표 오버레이 맵 (Spatial & Rhythm Map)
> **“리스트 스크롤 대신, 나랑 온도·시간이 겹치는 무리를 지도에서 잡는다”**

- **방식**: 모든 참여자를 2D 우주/지도 위에 점으로 시각화한다.
  - 가로축: `가볍게 경험 ↔ 진지하게 수상`
  - 세로축: `AI 적극 활용 ↔ 직접 구현 지향`
  - **시간표 오버레이**: 에브리타임 시간표 이미지를 올리면 **나와 공강·저녁 시간이 70% 이상 겹치는 사람들만 밝게 빛난다.**
- **매칭**: 지도 위에서 내 주변의 빛나는 점 3~4명을 **올가미(Lasso)로 묶으면** 즉시 해당 조합의 팀 궁합 리포트가 표시된다.
- **강점**: 복잡한 필터 조작 없이 캠퍼스 인재 풀의 분포와 나랑 결이 맞는 영역을 직관적으로 포착할 수 있다.

# 대학생 프로젝트 팀원 매칭 서비스 — 사전 기획 보고서

> **문서 목적**  
> 서비스 개발 착수 전, MVP의 핵심 범위·디자인 방향·사전 검증 및 준비 과제를 한눈에 정리한 실행 기획서입니다.

---

## 1. 서비스 개요

### 한 줄 정의
스펙 대신 **약점·성향·AI 활용 방식**을 입력하면, 내 AI 분신이 먼저 가상 팀플을 돌려보고 가장 합이 좋은 4인 팀과 모의회의 하이라이트를 데려다주는 **무거절 대학생 팀 빌딩 서비스**

### 해결하려는 문제
- **작성 장벽**: 저학년·초보자는 링크드인이나 포트폴리오에 쓸 경력이 부족해 시작부터 이탈한다.
- **기대치 불일치**: 기존 게시판(에브리타임·링커리어)은 “열심히 하겠다”는 말뿐이라 참여 온도(진지 vs 편함), AI 활용 태도, 협업 지뢰를 사전에 알기 어렵다.
- **거절 스트레스**: 좁은 캠퍼스 커뮤니티에서 DM으로 거절하거나 읽씹당하는 심리적 부담이 크다.

### 초기 런칭 전략
- **1차 타깃**: 연세대학교 재학생 (`@yonsei.ac.kr` 인증) — 초기 50~200명 밀도 확보
- **확장 전략**: 타 대학 확장 → 타 전공 크로스 팀 빌딩 → 공모전 주최사 타깃 네이티브 광고 수익화

---

## 2. MVP 핵심 기능 3가지

초기 소규모 풀에서도 첫날부터 차별화를 체감할 수 있도록 **딱 3가지 코어**에만 집중합니다.

### 기능 1. 2분 컷 ‘약점·성향’ 온보딩 *(매칭 #4 · 기술 #1, #2)*
경력이 적어도 부담 없이 끝낼 수 있는 카드형 프로필 생성 흐름입니다.
- **학교 인증**: `@yonsei.ac.kr` 이메일 인증
- **경력 자동 채우기 (선택)**: LinkedIn PDF·이력서·GitHub 링크 업로드 시 AI가 초안 자동 입력
- **필수 입력 4요소**
  - **참여 온도 & 시간**: 수상/진지 ↔ 경험/편함, 주당 투입 가능 시간
  - **AI 활용 스타일**: 짧은 상황 질문 3개로 자동 분류 *(예: AI 가속형 / 검증 중심형 / 직접 구현형)*
  - **약점 2장 + 강점 2장**: 선택지 + 짧은 자유 입력 *(예: 약점 `발표 울렁증`, 강점 `밤샘 백엔드 구현`)*
  - **협업 지뢰 1~2개**: 절대 못 참는 행동 *(예: `연락 두절`, `이해 없이 AI 복붙`)*

### 기능 2. AI 분신 사전 모의회의 & 팀 조합 리포트 *(매칭 #1 · 기술 #2, #3)*
리스트 탐색과 스와이프를 대체하는 서비스의 심장입니다.
- **공모전/주제 선택 → AI 분신 투입**: 관심 공모전을 고르면 백그라운드에서 가상 킥오프 실행
- **2단계 비용 통제 구조**
  - 1단계(0원): DB·규칙 기반으로 `온도 일치 + 시간 겹침 + 약점↔강점 보완 − 지뢰 충돌`을 계산해 상위 2~3팀만 추출
  - 2단계(저비용): 선정된 2~3팀만 **단일 Structured LLM 호출**로 6턴 가상 회의와 요약 생성
- **결과 카드 구성**
  - **팀 퍼즐 보완도**: 누가 누구의 약점을 덮어주는지 요약
  - **모의회의 하이라이트**: 실제 첫 회의 분위기 4~5줄 미리보기
  - **사전 합의 포인트**: 첫 미팅에서 맞출 1가지 제안 *(예: AI 초안 활용 범위)*

### 기능 3. 무거절 상호 소집 & 주간 팀 드롭 *(매칭 #5)*
거절 피로를 없애고 초기 유동성을 한곳에 모으는 결성 장치입니다.
- **선요청자 비공개**: 마음에 드는 조합에 “만나볼래요”를 눌러도 상대에겐 *“AI 분신이 딱 맞는 팀을 찾아왔어요”*로만 전달
- **상호 수락 시 언락**: 멤버들이 수락할 때만 실제 이름·전공·상세 프로필 공개
- **주간 팀 드롭 (Weekly Drop)**: 상시 소집과 함께 매주 정해진 시각(예: 금요일 밤 10시)에 일괄 매칭 결과를 공개해 유동성과 재방문 확보
- **외부 채팅 연계**: 팀 확정 후 자체 메신저 대신 카카오톡 오픈채팅·디스코드로 즉시 연결

### MVP에서 과감히 빼는 것 (Scope Cut)
- 자체 실시간 채팅·메신저 고도화
- 실시간 20분 화이트보드 협업방 *(동시접속 유동성 확보 후 v3)*
- 2D 은하계/시간표 맵 UI *(에브리타임 시간표 연동과 함께 v2)*
- LinkedIn 공식 양방향 API 연동 *(정책 제약 → PDF 파싱 + 완료 후 LinkedIn 복붙 요약으로 대체)*

## 3. 디자인 방향 & 톤앤매너

### 브랜드 무드
> **“가볍지 않은 솔직함, 무겁지 않은 전문성”**

- 링크드인처럼 딱딱한 취업·이력서 느낌은 피하고, 틴더처럼 가벼운 소개팅 앱 느낌도 피합니다.
- **에디토리얼 미니멀 + 위트 있는 카드 UI**를 지향합니다. *(참고 감성: Linear의 명료함 + Toss의 낮은 진입장벽 + 카드 게임의 직관성)*

### 비주얼 가이드라인 초안
- **레이아웃**: 모바일 웹 최우선 *(에브리타임·카톡 단톡방 링크 클릭 후 설치 없이 즉시 사용)*
- **배경 & 텍스트**: 순백(`#FFFFFF`)보다 눈이 편한 **웜 오프화이트(`#FAF9F6`)** 배경 + 짙은 차콜(`#18181B`) 텍스트
- **포인트 컬러**: 신뢰감 있는 딥 인디고 또는 코발트 블루 1종을 메인 CTA로 제한 사용
- **상태 태그**: 참여 온도(진지/편함), 약점·강점 카드는 채도가 낮은 파스텔 틴트 배지로 구분해 시각적 피로 최소화
- **타이포그래피**: `Pretendard` 기반, 넉넉한 행간과 카드 여백으로 “읽히는 기획서·프로필” 느낌 유지

### 핵심 화면 UX 포인트 (Key Screens)
1. **온보딩**: 긴 설문 폼 금지. **질문당 1화면 + 칩(Chip) 터치** 위주로 2분 내 완료 체감.
2. **AI 분신 회의 대기**: 지루한 스피너 대신 *“내 분신이 경영학도·디자이너와 첫 회의를 맞춰보는 중…”*처럼 진행 상황을 짧게 중계.
3. **결과 카드**: 한 화면에 팀 1개씩 집중 노출. `퍼즐 요약 → 말풍선 4~5줄 하이라이트 → 합의 포인트 1줄 → [만나볼래요]`의 단일 시선 흐름.
4. **카피라이팅 톤**: 평가하거나 면접 보는 어투를 빼고, 솔직하고 유쾌한 대학생 대화체 유지.

## 4. 개발 착수 전 해야 할 일 (체크리스트)

코드를 짜기 전에 아래 **4개 영역**을 먼저 끝내야 시행착오와 재작업을 줄일 수 있습니다.

### A. 사전 검증 — 코드 없이 핵심 가설 확인
- [ ] **연세대 재학생 10~15명 인터뷰**: 실제 공모전 팀 빌딩 실패 경험, 자주 겪은 협업 지뢰, 프로필 작성 시 부담 요소 수집
- [ ] **수동 MVP 테스트 (Wizard of Oz)**: 구글 폼으로 20명의 약점·성향을 모은 뒤, LLM 프롬프트로 직접 가상 모의회의 리포트를 만들어 전달 → *“이 리포트를 보고 실제로 만나고 싶은가?”* 반응 측정
- [ ] **초기 타깃 도메인 확정**: IT·개발 해커톤 중심 vs 경영·기획·마케팅 통합 공모전 중 1차 집중 범위 결정
- [ ] **서비스명·도메인 확정**: 캠퍼스에서 입에 붙고 공유하기 좋은 이름 선정

### B. 데이터·AI 사전 설계
- [ ] **온보딩 표준 분류표(Taxonomy) 확정**
  - 약점 카드 12~15종 / 강점 카드 12~15종
  - AI 활용 스타일 3~4유형 + 분류용 상황 질문 3문항
  - 협업 지뢰(Deal-breaker) 표준 태그 8~10종
- [ ] **1차 매칭 점수 공식 초안 작성**: 온도·시간·약점보완·지뢰감점의 가중치와 최소 매칭 기준선 설정
- [ ] **가상 모의회의 프롬프트 튜닝**: 출력이 뻔하거나 오글거리지 않도록 실제 페르소나 데이터로 20회 이상 테스트 및 JSON 스키마 고정
- [ ] **초기 공모전 시드 데이터 확보**: 연세대생이 관심 가질 만한 실제 공모전·해커톤 10~20건 사전 정리

### C. UX·화면 설계
- [ ] **화면 목록(IA) 7~9개 이내로 고정**: 랜딩 → 인증 → 온보딩 → 공모전 선택 → 분신 대기 → 결과 카드 → 소집/확정 → 내 프로필
- [ ] **Figma 핵심 화면 시안 제작**: 온보딩, 모의회의 결과 카드, 무거절 알림 화면 3종을 먼저 완성해 지인 피드백 반영
- [ ] **알림·거절 회피 카피라이팅 작성**: 미매칭 시에도 기분 나쁘지 않은 문구와 카카오톡 공유용 OG 이미지·문구 준비

### D. 운영·법무·런칭 준비
- [ ] **최소 법무 문구 준비**: 개인정보 처리방침, 이용약관, AI 생성 콘텐츠 고지(모의회의는 시뮬레이션임을 명시), 프로필 언락 동의
- [ ] **안전장치 정책 수립**: 허위 프로필·비매너 신고 절차, 부정 평판 외부 비공개 원칙 명문화
- [ ] **초기 시드 유저 50~100명 확보 플랜**: 연세대 학회·동아리·에브리타임 홍보 채널 리스트업 및 첫 ‘금요일 밤 팀 드롭’ 이벤트 기획
- [ ] **MVP 성공 지표(KPI) 정의**
  - 온보딩 완료율 *(목표 70% 이상)*
  - 모의회의 카드 확인 → “만나볼래요” 클릭률 *(목표 35% 이상)*
  - 실제 팀 결성(상호 수락) 전환율
  - 2주 내 재방문 또는 지인 추천 비율

## 5. 개발 전 준비 로드맵 (권장 2~3주)
